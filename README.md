# 🧠 PKEMS · 개인 지식·경험 기록장

> 글·사진·링크·영상을 **블로그처럼 이어 쓰고**, 내가 지정한 **구글 드라이브 폴더**에
> 마크다운(`.md`)·구글 문서·정리된 이름의 자료로 쌓아 두는 개인 지식·경험 관리 체계
> (Personal Knowledge & Experience Management System)

**`index.html` 파일 하나**로 동작합니다. 서버도, 빌드도, 프레임워크도 없습니다.
데이터는 **각자의 구글 드라이브**에만 저장되며 만든 사람을 거치지 않습니다.

# 왜 만들었나

## 흩어져 있어서 못 쓴다

지식과 정보와 경험이 **여러 도구와 여러 장소에 흩어져** 있습니다.
카톡에, 메모앱에, 드라이브 어딘가에, 학교 컴퓨터 바탕화면에, 사진첩에.
분명히 어딘가에 있는데 **필요할 때 꺼내 쓸 수가 없습니다.**
쌓이기는 하는데 쓰이지는 않는 것, 그건 없는 것과 크게 다르지 않습니다.

## AI가 알아들을 수 있는 형태로

AI와 함께 일하는 시간이 빠르게 늘고 있습니다.
그런데 AI에게 내 자료를 건네려면 **AI가 알아들을 수 있는 모양**이어야 합니다.
스크린샷 더미와 흩어진 한글 파일로는 「내가 3학년 과학을 어떻게 가르쳐 왔는지」를 물을 수 없습니다.

그래서 이 도구는 **모든 것을 마크다운(`.md`)으로** 남깁니다.
제목·태그·유형·날짜가 앞머리에 붙고, 기록끼리의 연결이 `[[대괄호]]`로 적힙니다.
**사람도 읽고 AI도 읽는 형식**입니다. 옵시디언에서 그대로 열리고, 한 해치를 통째로 묶어
AI에게 건넬 수도 있습니다.

## 2014년부터의 교직 생활을 돌아보려고

2014년부터 지금까지의 교직 생활을 **한 번 돌아보고 정리해 보고** 싶었습니다.
그 세월치 자료가 드라이브 여기저기에 잠들어 있습니다.

그래서 **이미 있는 것을 끌어오는 길**을 중요하게 여깁니다 —
`설정 → 저장 위치 → 📥 폴더 훑어서 가져오기` 는 앱 밖에서 만든 파일도 색인에 편입시킵니다.
새로 쓰는 것만 담는 도구였다면 이 도구를 만들 이유가 없었습니다.

## 가치 있다고 말하면서, 정말 관리하고 있는가

우리는 지식과 경험이 **가치 있다고 말합니다.** 그런데 그것을 체계적으로 관리하고 있습니까?
연수에서 배운 것, 실패한 수업에서 얻은 것, 아이들이 보여준 장면 —
**말로만 소중하고 실제로는 흘려보내고 있지 않은지.**

남을 탓할 일이 아니라 **나부터 정리가 필요하다**는 데서 시작했습니다.

## 수업 자료도 마찬가지다

수업 자료도 **한 번 쓰고 버리는 것**이 되기 쉽습니다.
같은 단원을 여섯 번 가르쳤는데 여섯 번 다 처음부터 만드는 일이 벌어집니다.

**가치 있는 자료에 깊이를 더해 가며 모아 두는 것**,
「작년의 나」가 「올해의 나」에게 무언가를 남겨 주는 것.
그래서 기록끼리 **연결**되고, 지난 기록이 **백링크**로 저절로 되살아나게 만들었습니다.

## 현장연구자에게는 데이터가 필요하다

교실에서 연구하는 사람에게 **데이터를 잘 모으는 일**은 연구의 절반입니다.
문제는 「어떻게 모을 것인가」입니다. 나중에 정리하겠다고 미루면 영영 안 됩니다.

그래서 **모으는 순간의 마찰을 줄이는 데** 공을 들였습니다 —
폰에서 공유 한 번, 웹에서 즐겨찾기 한 번, 칠판 앞에서 손으로 한 줄,
회의 중에 녹음 버튼 하나. **나중이 아니라 그 자리에서** 남게.

## 왜 하필 「개인」인가

기관용도 학교용도 아닌 **개인**입니다.
**개인에게 가치 있는 정보가 무엇인지**를 먼저 알아야 하기 때문입니다.
남이 정해 준 분류 체계에 내 경험을 밀어 넣는 방식으로는 그걸 알 수 없습니다.

그래서 **유형도, 태그도, 파일 이름 규칙도, 폴더 정리 방식도 쓰는 사람이 직접 정합니다.**
쓰다 보면 「나에게 무엇이 가치 있었는지」가 그 구조에 드러납니다.

## 그리고 — 나눌 수 있어야 한다

정보가 **어떻게 나에게 의미를 가지는지**를 스스로 알아내 **지식으로 바꾸고**,
그것을 **남과 나눌 수 있어야** 비로소 한 바퀴가 돕니다.

그래서 「🔗 링크로 공유」가 있습니다. 주소 하나면 동료가 로그인 없이 읽습니다.
그리고 나누기 전에 **사진을 한 번 더 확인시킵니다** — 아이들이 찍힌 사진이니까요.

| 문제의식 | 이 도구가 하는 일 |
|---|---|
| 여러 곳에 흩어져 있다 | 📥 **웹 캡처** (폰 공유 시트 · PC 즐겨찾기) · 화면 아무 데나 **끌어다 놓기** · 📥 **폴더 훑어서 가져오기** |
| AI가 알아듣는 형태로 | 모든 기록을 **마크다운**으로 · front-matter · `[[연결]]` · 옵시디언 호환 · 📚 **엮어내기**로 통째로 뽑기 |
| 2014년부터를 정리 | 📥 **폴더 훑어서 가져오기** (5단계·400폴더까지) · 🗂 **폴더 구조**로 쌓인 모양 보기 |
| 체계적으로 관리하는가 | 🏷️ **유형 직접 만들기** · 📛 **파일 이름 규칙 직접 정하기** · 5가지 **폴더 정리 방식** |
| 자료에 깊이를 더해 가며 | 🔗 **연결 · 백링크 · 관계망** — 지난 기록이 저절로 되살아난다 |
| 그 자리에서 모으기 | 📸 **캡처·촬영** · ✍️ **손 메모** · 🎙️ **녹음·받아쓰기** · ⏳ **임시저장** (꺼져도 그대로) |
| 개인에게 가치 있는 것 | 분류를 **쓰는 사람이 정한다.** 🗂 폴더 구조가 「내가 무엇을 쌓아 왔나」를 보여준다 |
| 지식으로 바꾸어 나누기 | 🔗 **링크로 공유** (글 하나 · 폴더 통째로) · 🛡 **공유 전 사진 확인** · 🔲 **사진 가리기** |

## 바랐지만 못 한 것 — 왜 못 하는지까지

되는 척하는 기능이 안 되는 기능보다 위험합니다. 그래서 남겨 둡니다.

| 바랐던 것 | 왜 안 되나 | 대신 |
|---|---|---|
| **손글씨를 글자로 자동 인식** | 브라우저에 그 기능이 없습니다. 외부 AI에 맡기려면 **쓰는 사람마다 API 키**를 발급받아야 해서, 「링크 열고 로그인」 두 단계인 지금의 진입 문턱이 확 올라갑니다 | ✍️ **손 메모** — 손으로 쓴 그대로 그림으로 남깁니다. 검색은 제목·태그로 |
| **화면 꺼도 백그라운드 녹음** | 다른 앱으로 넘어가거나 화면이 꺼지면 **브라우저가 마이크를 놓습니다.** 웹앱으로는 못 넘는 벽입니다 | 🎙️ 창을 열어 둔 동안 녹음 + **받아쓰기**. 화면이 안 꺼지게 붙잡고, 벗어난 사실도 알려 줍니다 |
| **녹음을 알아서 요약·정리** | AI 몫입니다 (위와 같은 이유) | 받아 적은 글이 그대로 남으니, 필요하면 그걸 AI에게 건네면 됩니다 |
| **얼굴 자동 모자이크** | 브라우저 얼굴 인식은 **사실상 없고**, 외부 모델을 붙여도 **옆모습·뒷줄·가려진 얼굴을 자주 놓칩니다.** 「자동으로 가려 준다」를 믿게 만들어 놓고 놓치는 것이, 사람이 직접 보는 것보다 **더 위험합니다** | 🔲 **사진 가리기** — 얼굴 위를 톡 누르면 지워집니다. 쓸면 줄줄이. 그리고 🛡 **공유 전에 사진을 다시 한 번 확인**시킵니다 |
| **HTML을 웹페이지로 공유** | 구글이 **2016년에 드라이브 웹호스팅을 없앴습니다.** HTML 파일을 눌러도 소스가 보이거나 내려받아집니다 | 📄 **구글 문서**로 공유 — 글·사진이 한 장으로 예쁘게, 폰에서도 그대로 |
| **아이폰에서 공유 시트** | 사파리가 `share_target` 을 지원하지 않습니다 | 주소를 복사해 붙여넣거나 사진첩에서 골라 넣기 |
| **로그인이 아예 안 풀리게** | 갱신용 열쇠를 받으려면 **비밀번호를 숨길 서버**가 필요합니다. 그러면 「파일 하나·서버 없음」이 무너집니다 | 1시간 유지 + 풀리면 **「다시 연결」 한 번** |

## 2. 기능

### ✍️ 블록 이어쓰기 에디터
한 번 입력하고 끝이 아니라, **글 → 사진 → 링크 → 소제목 → 글 → 파일** 순서로
원하는 만큼 이어 붙입니다. 각 블록은 `↑ ↓` 로 순서를 바꾸고 `✕` 로 지웁니다.

| 블록 | 저장되는 마크다운 |
|---|---|
| 📝 글 | 문단 |
| 🔠 소제목 | `## 소제목` |
| ❝ 인용 | `> 인용` |
| 🖼️ 사진 | `![캡션](파일명)` + 드라이브 링크 주석 |
| 📸 화면 캡처 | 사진 블록과 동일 |
| ✍️ 손 메모 | 손으로 쓴 것을 그림 한 장으로 — 사진 블록과 동일 |
| 🎙️ 녹음 | 소리 파일 + 받아 적은 글, 두 블록으로 |
| 📎 파일·영상 | `📎 [파일명](드라이브 링크)` — 영상·소리는 카드에서 바로 재생 |
| 🔗 링크 | `🔗 [설명](URL)` |
| 🧩 코드 삽입 | HTML 그대로 (유튜브·구글문서 등 임베드) |
| ➖ 구분선 | `---` |

버튼은 전부 `＋` 로 통일되어 있습니다.

### 📸 캡처 · 사진 넣기 (PC / 모바일 공통)
버튼을 누르면 **넣는 방법을 고르는 시트**가 뜹니다. 기기에 따라 선택지가 달라집니다.

| PC | 📱 모바일 |
|---|---|
| 📋 **클립보드에서 붙여넣기** ← 가장 빠름 | 🖼️ **갤러리에서 고르기** — 스크린샷·사진 |
| 🖼️ 이미지 파일에서 고르기 | 📷 카메라로 찍기 — 칠판·유인물 바로 |
| 📷 웹캠으로 찍기 — 화면 보며 촬영 | 📋 클립보드에서 붙여넣기 |
| 🖥️ 화면 캡처하기 — 창 공유 화면이 뜸 | |

**창 공유 화면이 번거로우면 클립보드 방식을 쓰세요.**
`Win+Shift+S`(맥 `⌘⇧4`)로 캡처 → 앱에서 **아무 데나 `Ctrl+V`** 하거나 «📋 클립보드에서 붙여넣기».
선택 대화상자가 전혀 뜨지 않습니다. 글 칸에 커서가 없어도 붙습니다.

**웹캠**은 카메라 화면을 미리 보면서 «찍기» 를 누르는 방식입니다.
(예전에는 이 버튼이 PC에서 파일 선택창만 열려 아무 일도 안 했습니다 — 고쳤습니다.)

**어느 쪽을 고르든 그다음은 똑같습니다** — 이미지가 뜨면 **드래그해서 필요한 영역만** 잘라 넣습니다.
선택하는 동안 잘릴 크기가 `611 × 815 px` 처럼 실시간으로 보이고, `선택 영역 사용` / `전체 사용` /
`다시 고르기` 를 누르면 됩니다. 마우스·터치 모두 지원합니다.
자르기가 귀찮으면 시트 아래 **«자르지 않고 원본 그대로 넣기»** 를 켜 두면 됩니다.

- 별도 프로그램·확장 프로그램 없이 브라우저 기능만 씁니다.

  드라이브에는 아래 이름 규칙대로 저장됩니다.

### 🔲 사진 가리기 — 얼굴을 톡 눌러서 한 번에

내용 칸 위의 **「🔲 사진 가리기」** 를 누르면 **이 기록의 사진이 전부 한 줄로** 늘어섭니다.
얼굴이 있는 사진만 골라 들어가서, **얼굴 위를 톡 누르면 그 자리가 동그랗게 지워집니다.**

- **드래그할 필요가 없습니다.** 단체사진이면 얼굴마다 한 번씩 톡톡 누르면 끝
- **쓸어 넘기면 줄줄이** 지워집니다 — 뒷줄 아이들을 한 번에
- 원 크기 4단계 (`작게` `보통` `크게` `아주 크게`). 누르기 전에 **얼마나 가려질지 동그라미로 미리 보입니다**
- 가린 사진에는 **✓** 가 붙어서, 어디까지 했는지 한눈에 보입니다
- `↩ 한 번 되돌리기` · `이 사진 원래대로` · `← 이전 / 다음 →` 으로 사진을 넘나듭니다
- **이미 드라이브에 올라간 사진도 됩니다.** 저장하면 **같은 파일에 덮어써집니다**
  (파일 이름·주소가 그대로라 글 속 링크와 색인이 어긋나지 않습니다)

네모로 잘라 가리고 싶으면, 자르기 화면의 **「🔲 모자이크로 가리기」** 를 쓰면 됩니다.
사진 블록 아래 **「🔲 가리기」** 로 한 장만 열 수도 있습니다.

> 가린 것은 **올라가는 사진 자체에서 지워집니다.** 미리보기만 가리는 게 아닙니다.
> 학생 얼굴·이름표가 든 사진은 **공유 링크를 만들기 전에** 여기서 지우세요.
> (공유 단추를 누르면 사진을 다시 한 번 확인시켜 줍니다.)

### 🎙️ 녹음 · 받아쓰기

**`＋ 녹음`** 을 누르면 큰 시계와 소리 크기 막대가 나옵니다.
**막대가 움직이면 담기고 있는 것**이고, 멈춰 있으면 마이크가 죽은 것입니다.

- 말하면 아래 칸에 **그대로 받아 적힙니다.** 틀린 곳은 그 자리에서 고치면 됩니다
- 브라우저에 딸린 음성인식을 씁니다 — **따로 키를 받을 것도, 돈 낼 것도 없습니다**
- 넣으면 **소리 파일 + 받아 적은 글**이 함께 블록으로 들어갑니다
- 녹음하는 동안 화면이 꺼지지 않게 붙잡아 둡니다

> ⚠️ **이 창을 열어 둔 동안에만 녹음됩니다.** 다른 앱으로 넘어가거나 화면이 꺼지면
> 브라우저가 마이크를 놓습니다. 「켜 두면 알아서 기록」은 웹앱으로는 안 되는 일이라,
> 숨기지 않고 화면에 적어 두었고 화면을 벗어난 사실도 알려 줍니다.
> 받아쓰기는 **크롬** 이 가장 잘 됩니다.

#### 🔗 링크로 공유 — 주소 하나만 보내면 됩니다

전체 보기의 **「🔗 링크로 공유」** 를 누르면 **두 가지 중에 고릅니다.**
어느 쪽이든 지금은 비공개인 것을 누르는 순간 **「링크가 있는 사람 = 읽기」로 바꾸고**
주소를 **바로 복사**해 줍니다.

| | 넘어가는 것 | 어울리는 때 |
|---|---|---|
| 📄 **글 하나만** (구글 문서) | 글과 사진이 **한 장으로 예쁘게** | 동료에게 수업 한 편 보여주기 |
| 📁 **폴더 통째로** | 원본 사진·학습지·`.md`·HTML **파일 전부** | 자료를 통째로 넘겨주기 |

- 받는 사람은 **로그인도, 앱 설치도 필요 없습니다.** 폰에서도 그대로 열립니다
- 검색에는 걸리지 않습니다. 다만 **링크가 퍼지면 되돌릴 수 없습니다**
- 필요 없어지면 각각 **「공유 끄기」**

##### 🛡 공유 전 사진 확인 관문

**「가리는 걸 깜빡했다」가 진짜 사고입니다.** 그래서 사진이 든 기록은
공유 단추가 **처음엔 눌리지 않습니다.** 그 기록의 사진이 전부 눈앞에 늘어서고,
**「확인했습니다 — 남에게 보여도 되는 사진입니다」** 를 체크해야 열립니다.
사진은 눌러서 크게 볼 수 있고, 문제가 보이면 창을 닫고 **✏️ 편집 → 🔲 가리기** 로
지운 뒤 다시 저장하면 됩니다.

> ⚠️ **폴더 공유는 「기록마다 폴더 하나」 방식일 때만 됩니다.**
> 다른 방식은 여러 기록이 한 폴더에 같이 있어서, 폴더를 열면 **남의 기록까지 보입니다.**
> 그래서 아예 막아 두고 이유를 화면에 적어 둡니다.

> ⚠️ **HTML 파일은 드라이브에서 「웹페이지」로 열리지 않습니다.**
> 구글이 2016년에 드라이브 웹호스팅을 없앴습니다. 폴더를 공유하면 HTML 파일이
> 딸려 가긴 하지만, 눌러도 소스가 보이거나 내려받아집니다.
> **사람에게 보여줄 것은 구글 문서 쪽**입니다.

아래쪽 **🔗 연결** 칸의 기록을 누르면 그 기록으로 **곧바로 넘어갑니다.**
로그인이나 업로드 없이도 열리므로, 드라이브에 안 올린 기록도 그대로 볼 수 있습니다.

### 📚 엮어내기 — 흩어진 기록을 한 권으로
목록 위 **`📚 엮어내기`** 를 누르면, 고른 기록들을 **하나의 파일**로 묶어 내려받습니다.
연수 자료·수업 산출물·포트폴리오를 그대로 뽑아낼 수 있습니다.

| 고르는 방법 | 설명 |
|---|---|
| 지금 화면 그대로 | 유형·태그·검색으로 걸러 둔 것이 그대로 후보가 됩니다 |
| 체크박스 | 그중에서 담을 것만 다시 고릅니다 |
| **연결된 기록도 함께** | 고른 기록에서 `[[링크]]`·관계망·**백링크**로 이어진 기록을 **한 단계 더** 끌어옵니다 |

담기는 것 — **표지**(제목·편수·기간) · **목차**(눌러서 이동) · 각 편의 본문 ·
유형·날짜·태그 · **🔗 연결 정보**(나감/들어옴)

| 형식 | 쓰임 |
|---|---|
| **`.md`** | 옵시디언·노션·깃허브에 그대로. 연결은 `[[제목]]` 으로 살아 있습니다 |
| **`.html`** | 브라우저로 바로 읽기. 목차·장 사이 이동이 **내부 링크**로 연결되고, **인쇄하면 장마다 페이지가 넘어가** 책처럼 나옵니다 (PDF로 저장하면 그대로 책) |

> 예: `#과학` 태그로 거른 뒤 → 「연결된 기록도 함께」 켜기 → `.html` 로 내려받기
> → 그 학기 과학 수업 기록이 목차 달린 한 권이 됩니다.

### 🔎 찾기 · 거르기
목록 위에 **유형 줄**과 **🏷 태그 줄**이 있습니다.

- **태그를 여러 개** 고르면 **그 태그를 모두 가진** 기록만 남습니다
- 기록 카드 안의 `#태그` 를 눌러도 바로 그 태그로 좁혀집니다
- 태그 옆 숫자는 **지금 조건에서 남는 기록 수**입니다 (0개짜리는 아예 안 보입니다)
- 검색창은 제목·본문·태그를 한꺼번에 훑습니다
- 조건이 걸려 있으면 **`✕ 필터 지우기`** 가 나타납니다

### 📌 맨 위 고정 (즐겨찾기)
기록 제목 아래 날짜 옆의 **`📌 고정`** 을 누르면 그 기록이 **목록 맨 위로** 올라갑니다.

- 고정한 기록은 **위쪽 줄이 노란색**으로 바뀌어 한눈에 구분됩니다
- 유형 줄에 **`📌 고정 N`** 칩이 생기고, 누르면 **고정한 것만** 봅니다
- 고정 여부는 드라이브 색인에 함께 저장되어 **다른 기기에서도 그대로**입니다
- 자주 여는 수업 자료나 진행 중인 프로젝트를 위에 붙여 두는 용도입니다

### 📏 목록이 길어지지 않게
- **사진은 작은 썸네일**로 나옵니다. **누르면 크게** 보이고, 화살표로 넘겨 볼 수 있습니다
  (미리보기에도 제목·글과 함께 사진이 그대로 보입니다)
- 첨부 이름·링크 주소가 길면 한 줄에서 `…` 로 잘립니다 (마우스를 올리면 전체가 보임)
- 삽입한 페이지는 **아래 모서리를 끌어 높이를 바꿀 수 있습니다**
- 기록마다 위쪽에 **파란 줄**이 있어 어디서 끊기는지 한눈에 보입니다

### 📥 폴더에서 가져오기 — 색인에 없는 파일 편입
앱은 **색인 파일(`PKEMS-index.json`)** 을 보고 목록을 만듭니다. 그래서 옵시디언에서 만든 노트나
드라이브에 직접 넣은 `.md` 는 목록에 안 나옵니다.

`설정 → 저장 위치 → 📥 폴더 훑어서 가져오기` 를 누르면:

1. 연결한 폴더 아래를 **5단계까지 파고들며** 훑습니다 (학년 › 학기 › 과목 › … 처럼 여러 겹으로 정리해 두어도 찾습니다)
   - 폴더가 아주 많으면 **400곳까지만** 훑고 그 사실을 알려 줍니다. 그때는 더 안쪽 폴더를 직접 연결해 한 번 더 가져오세요
   - 훑는 동안 「폴더를 훑는 중… 37곳 · 파일 210개」처럼 진행 상황이 보입니다
2. 색인에 없는 `.md` 를 찾아 **front-matter를 읽습니다** (제목·유형·태그·작성일)
3. 본문을 블록으로 되돌립니다 — 소제목 `##`, 인용 `>`, 구분선, 이미지, 링크, 삽입 코드
4. **같은 폴더의 사진·첨부를 파일명으로 찾아 자동 연결**합니다
5. 색인에 넣고 드라이브에 다시 씁니다

`id` 가 이미 있는 기록은 건너뛰므로 여러 번 눌러도 중복되지 않습니다.

### 🔗 링크 미리보기
`＋ 링크` 로 넣은 주소는 목록에서 **미리보기 카드**로 보입니다.

- 사이트 아이콘 + 제목(설명) + 주소가 한 줄로 정리됩니다
- **유튜브 주소는 영상 미리보기 그림**이 함께 붙습니다
- 이름이 길면 `…` 로 잘리고, 마우스를 올리면 전체 주소가 보입니다

> 다른 사이트의 제목·대표 이미지를 직접 읽어오지는 못합니다.
> 브라우저 보안(CORS) 때문이며, 서버 없이 도는 앱이라 그렇습니다.
> 설명을 넣고 싶으면 링크 블록의 **설명 칸**에 적어 주세요.

### 🎬 영상 · 소리 · 사진 슬라이드
- **영상/오디오 파일**을 넣으면 **카드에서 바로 재생**됩니다.
  올리기 전에는 브라우저에서 직접, 올린 뒤에는 «▶ 재생» 을 누르면 구글 드라이브 플레이어가
  열립니다 (200MB 영상을 통째로 내려받지 않고 스트리밍).
- **사진을 여러 장** 넣으면 카드에서 **바둑판 썸네일**로 묶이고,
  하나를 누르면 **전체 화면 슬라이드**가 열립니다.
  - `←` `→` 키 또는 좌우 버튼으로 넘기기, 아래 필름 스트립으로 바로 이동
  - 휴대폰에서는 **손가락으로 넘기기**(스와이프)
  - `3 / 12` 처럼 위치 표시, `Esc` 로 닫기, 「드라이브에서 열기」 버튼

### 🧩 코드 삽입 — 붙여넣으면 바로 보임
`＋ 코드 삽입` 에 HTML 삽입 코드를 붙여넣으면 **그 자리에서 바로 렌더링**됩니다.

**주소만 붙여넣어도 됩니다** — 아래는 자동으로 삽입 코드로 바뀝니다.

| 붙여넣는 것 | 결과 |
|---|---|
| 유튜브 주소 (`youtube.com/watch?v=…`, `youtu.be/…`, Shorts) | 영상 플레이어 |
| Vimeo 주소 | 영상 플레이어 |
| 구글 문서·시트·슬라이드 주소 | 문서 미리보기 |
| 구글 드라이브 파일 주소 | 파일 미리보기 |

높이는 직접 조절할 수 있고(기본 360px), 저장하면 마크다운·구글문서·HTML 사본에 모두 들어갑니다.

> 🔒 삽입한 코드는 **격리된 틀(sandbox iframe) 안에서만** 실행됩니다.
> `allow-same-origin` 을 주지 않아서, 붙여넣은 코드가 기록 데이터나 로그인 정보에 손댈 수 없습니다.

### 📦 큰 파일 · 영상 용량 (최대 200MB)
파일 하나당 **200MB** 까지 올라갑니다. 8MB 씩 끊어 보내는 방식(resumable)이라
큰 영상도 브라우저가 멈추지 않습니다. 6MB 넘는 파일은 상단에 `↑ 파일명… 42%` 로 진행률이 뜹니다.

**영상은 어느 정도가 적당한가**

| 화질 | 200MB 로 담기는 길이(대략) |
|---|---|
| 720p | 약 20~30분 |
| **1080p** | **약 10~15분** ← 수업 장면 기록에 적당 |
| 4K (요즘 폰 기본) | 약 1~2분 — **너무 짧습니다** |

- 수업 한 장면·활동 하나를 담는 정도면 200MB 안에 충분히 들어갑니다.
- **한 시간짜리 수업 전체**처럼 긴 영상은 파일로 올리지 마세요.
  유튜브에 **«일부공개»** 로 올린 뒤 `＋ 코드 삽입` 에 주소를 붙여넣는 편이 낫습니다
  (드라이브 용량을 안 먹고, 재생도 훨씬 매끄럽습니다).
- 폰에서 찍을 때 설정을 **1080p / 30fps** 로 두면 4K보다 훨씬 오래 담깁니다.
- 200MB 를 넘기면 앱이 건너뛰면서 위 방법을 안내합니다.

업로드 전 파일은 브라우저 메모리가 아니라 **IndexedDB 에 원본 그대로** 보관되어,
새로고침하거나 오프라인이어도 그대로 남았다가 연결되면 올라갑니다.
- ⚠️ **화면 직접 캡처는 `https://` 또는 `localhost` 에서만** 됩니다 (브라우저 보안 정책).
  **모바일 브라우저는 화면 캡처 자체를 지원하지 않습니다** — 폰에서 스크린샷을 찍고
  «갤러리에서 고르기» 로 넣으면 PC와 완전히 같은 결과가 됩니다. 앱이 그렇게 안내합니다.

### 📥 파일 탑재 (화면 아무 곳에나 드롭)
파일을 **브라우저 창 어디에 끌어다 놓아도** 붙습니다. 놓을 자리를 찾을 필요가 없습니다.
- 놓는 순간 전체 화면에 `📥 여기에 놓으면 기록에 추가됩니다` 안내가 뜹니다
- 사진이면 사진 블록, 나머지는 파일 블록으로 자동 구분
- 여러 개를 한 번에 놓으면 순서대로 쌓입니다
- 글 칸에 **Ctrl+V 붙여넣기**도 그대로 됩니다
- 텍스트를 드래그할 때는 반응하지 않습니다 (파일일 때만)

### 🔗 연결 · 백링크 · 관계망

> 앱 안에 **❔ 사용법** 버튼이 있습니다. 4개 탭(연결이란 / 잇는 법 / 백링크 / 관계망)으로
> 예시와 함께 설명해 두었으니, 처음 쓰는 사람에게는 그걸 먼저 보여주세요.

**연결하는 방법은 두 가지입니다. 결과는 같습니다.**

**① 글 쓰다가** — 내용 칸에 `[[` 를 치면 기존 기록 목록이 뜹니다 (↑↓ 이동, Enter 선택).
없는 제목을 적으면 점선으로 표시되고, 누르면 그 제목으로 새 기록이 시작됩니다.

**② 관계망에서** — 점을 누르고 「🔗 다른 기록과 잇기」 → 상대 점을 누르면 끝.
이때 **어떤 관계인지 설명**을 달 수 있습니다 (「여기서 배움」, 「근거가 됨」 …).

각 기록 카드 아래에 **연결 줄**이 붙습니다.

```
🔗 연결 — 나감 2 · 들어옴 1
  → 온도계 사용법 · 여기서 배움    → 모둠 운영 원칙    ← 물의 상태변화 수업
```

`→` 는 내가 건 연결, `←` 는 **나를 가리킨 기록(백링크)** 입니다.
B에서는 아무것도 안 했는데 B를 열면 「A가 나를 가리킨다」가 저절로 보이는 것, 이게 백링크입니다.

**🕸️ 관계망** — 보기만 하는 그림이 아니라 **관계를 만드는 도구**입니다.

- 점 = 기록 (유형별 색, 연결이 많을수록 큼) · 회색 점 = 태그(기본 꺼짐)
- 실선 **화살표** = 기록끼리의 연결(방향 표시) · 점선 = 같은 태그 공유
- **점을 누르면 정보 창**이 열립니다 — 미리보기, 나가는 연결, 들어오는 백링크가 한 곳에
- 정보 창에서 **연결 만들기 / 연결 끊기 / 기록 열기**
- 연결에 붙인 설명은 **선 위에 표시**됩니다
- 선택한 점과 이웃만 밝게, 나머지는 흐리게
- 배치가 점점 안정되어 멈춥니다 (계속 흔들리지 않음)
- 끌어 옮기기, 휠 확대·축소, 빈 곳 끌어 이동 — **모바일에서도 터치로 동일**

### 🗂 폴더 구조 — 드라이브가 지금 어떻게 생겼는지

맨 위 **`🗂 폴더 구조`** 를 누르면 **탐색기처럼 위에서 아래로** 펼쳐집니다.
`▸` 를 눌러 접었다 폅니다.

```
📂 05_도구개발/                                   기록 14편 · 바로가기 10
  📂 과학실험/                                              기록 2편
    📝 2026-06-15_경험_알코올램프 안전.md
    📄 2026-06-15_경험_알코올램프 안전                    ⏳ 올리기 전
    🖼 2026-06-15_사진_01.jpg                              1.5MB
  📂 3학년/                                              바로가기 6
    🔗 2026-06-15_경험_알코올램프 안전.md                    바로가기
```

- **지금 「폴더 정리 방식」 그대로** 그립니다. 방식을 바꾸면 이 그림도 바뀝니다
- **한 기록의 파일끼리 붙여 둡니다** — 글 → 구글문서 → HTML → 사진·파일 차례.
  이름순으로 늘어놓으면 글과 그 글의 사진이 떨어져 무엇이 한 벌인지 안 보입니다
- 최근 기록이 위로 옵니다
- **📝 를 누르면 그 기록이 열립니다**
- 아직 안 올라간 것은 `⏳ 올리기 전`, 태그 바로가기는 `바로가기` 로 표시됩니다
- **모두 접기 / 모두 펴기**

드라이브를 따로 열지 않고도 **「내 자료가 지금 이렇게 쌓여 있구나」** 가 보입니다.

#### 옵시디언에서 그대로 열립니다

1. **구글 드라이브 데스크톱 앱**을 설치해 폴더를 PC에 동기화합니다
2. 옵시디언에서 **「폴더를 볼트로 열기」** → 동기화된 그 폴더 선택

링크·백링크·그래프 뷰가 바로 동작합니다. 파일명이 `{날짜}_{유형}_{제목}.md` 라서
옵시디언이 `[[제목]]` 을 못 찾을 수 있는데, front-matter 에 **`aliases`** 를 넣어 해결했습니다.

```yaml
aliases: ["물의 상태변화 수업", "k1"]
```

> ⚠️ **옵시디언에서 파일 이름을 바꾸거나 옮기지 마세요.** 이 앱은 색인(`PKEMS-index.json`)
> 기준으로 목록을 만들기 때문에 어긋납니다. **읽기·탐색은 옵시디언, 편집은 앱** 으로 나누는 게 안전합니다.
> (구글 문서 사본을 함께 저장하는 경우, 옵시디언 볼트에는 `.gdoc` 바로가기가 같이 보입니다.)

### 🏷️ 기록 유형 직접 만들기
기본 5종(경험·지식·아이디어·자료·회고)을 **이름·아이콘·순서까지 자유롭게** 바꾸거나
새로 추가할 수 있습니다. 만든 유형은 작성 화면의 선택 버튼과 목록 필터에 바로 반영됩니다.
→ `설정 → 기록 유형`

### 📛 파일 이름 규칙 직접 정하기
드롭다운에서 고르거나, 태그를 눌러 **직접 조립**합니다. 실시간 미리보기가 나옵니다.
→ `설정 → 파일 이름`

사용 가능한 태그:
`{폴더명}` `{하위폴더}` `{날짜}` `{시간}` `{유형}` `{제목}` `{번호}` `{원본이름}` `{확장자}`

```
{폴더명}_{날짜}_{제목}_{번호}         →  05_도구개발_2026-08-16_2단원 정리_01.png
{날짜}_{제목}_{번호}                →  2026-08-16_수업 회고_01.png
{유형}_{날짜}_{시간}_{번호}_{원본이름}  →  경험_2026-08-16_1421_01_IMG_4821.png
{폴더명}_{날짜}_{유형}_{제목}         →  05_도구개발_2026-08-16_경험_수업 회고.md
```

**`{폴더명}` 이 폴더 이름 자동 동기화입니다.** 지금 연결된 드라이브 폴더 이름이 파일명 앞에
자동으로 붙고, 폴더를 다른 곳으로 바꾸면 그 이후 저장분부터 새 폴더명이 따라붙습니다.
(`{하위폴더}` 는 "자료" 같은 하위 폴더 이름입니다.)

- `{확장자}` 를 안 쓰면 원래 확장자가 자동으로 붙습니다.
- 같은 이름이 이미 있으면 `-2`, `-3` 이 붙습니다.
- 폴더 연결 전이라 `{폴더명}` 이 비면, 앞에 `_` 가 남지 않도록 알아서 정리합니다.

### ⏳ 임시저장 — 쓰다가 꺼져도 그대로
저장 버튼을 누르지 않아도 **작성 중인 내용이 계속 임시 보관**됩니다.
브라우저가 꺼지거나, 탭을 닫거나, 배터리가 나가도 다시 열면 그 자리에서 이어 쓸 수 있습니다.

- 1.5초마다 자동 저장 + 탭을 벗어나거나 닫는 순간에도 저장
- **제목·태그·유형·모든 블록·붙여둔 사진과 파일까지** 그대로 복구
  (파일 본문은 IndexedDB 에 있어서 새로고침해도 살아남습니다)
- 편집 중이던 기록이면 «편집 중» 상태까지 기억합니다
- 위쪽에 `⏳ 임시 보관 중 · 시각` 띠가 뜨고, 「새로 쓰기」로 버릴 수 있습니다
- 저장 버튼을 누르면 임시본은 자동으로 정리됩니다

> ⚠️ 이건 **그 기기 안에서만** 동작합니다. 드라이브로는 «기록 저장» 을 눌러야 올라갑니다.

### 📱 모바일 ↔ PC 연동
- **자동 동기화** — 폰에서 쓰고 PC 탭으로 돌아오면(창이 다시 보이는 순간) 알아서 최신을 끌어옵니다.
  네트워크가 돌아왔을 때도 자동으로 재시도합니다. 상단에 `☁ 방금 동기화` 로 상태가 보입니다.
- **삭제도 전파** — 폰에서 지운 기록이 PC에서 되살아나지 않습니다 (삭제 기록을 색인에 남김).
- **충돌 처리** — 같은 기록을 양쪽에서 고쳤으면 **나중에 고친 쪽**이 남습니다.
- **저장 안정성** — 아직 못 올린 사진·파일은 **IndexedDB** 에 보관합니다.
  (휴대폰 사진 두어 장이면 localStorage 한도를 넘겨 기록이 통째로 날아갈 수 있어서입니다.)
  비행기 모드에서 써 두고 나중에 연결해도 그대로 올라갑니다.
- **모바일 UI** — 입력칸 16px(iOS 자동 확대 방지), 하단 고정 도구막대,
  아래에서 올라오는 시트형 설정창, 터치 타깃 확대.

#### 🔑 새로고침해도 로그인이 안 풀립니다

구글이 주는 열쇠(토큰)는 **1시간짜리** 입니다. 예전에는 그것을 화면 안에만 들고 있어서
**새로고침 = 로그아웃** 이었습니다. 특히 폰에서 앱으로 설치해 쓰면 매번 풀렸습니다.

- 이제 만료시각과 함께 보관해 두고, **남은 시간이 있으면 그대로 이어 씁니다**
- 구글 로그인 창은 **사용자가 무언가 누른 직후에만** 엽니다.
  아무것도 안 눌렀는데 열면 브라우저가 「내가 안 시킨 창」으로 보고 막습니다 —
  **폰에서 로그인이 풀린 것처럼 보이던 진짜 이유가 이것이었습니다**
- 그래도 풀리면 조용히 넘어가지 않고 **「구글 연결이 풀렸습니다 — 기록은 그대로 있습니다」**
  띠가 뜹니다. **한 번 누르면 그 자리에서 이어집니다**
- 「연결 해제」를 누르면 보관해 둔 열쇠까지 지웁니다

> 「아예 안 풀리게」는 서버 없이는 불가능합니다. 갱신용 열쇠를 받으려면 비밀번호를 숨길
> 서버가 있어야 하고, 그러면 이 앱의 「파일 하나·서버 없음」이 무너집니다.

#### 📤 업로드가 멈춘 것처럼 보이던 문제

예전에는 조각 하나(8MB)가 **다 올라가야** 진행률이 움직였습니다. 폰 업로드 속도로
8MB면 20~60초 — **그동안 `0%` 에 붙어 있어서 멈춘 줄 알았습니다.**
게다가 신호가 끊기면 요청이 **오류도 없이 영원히 매달렸습니다.**

- 조각 보내기를 `fetch` 에서 `XMLHttpRequest` 로 바꿨습니다.
  `fetch` 는 올라가는 중 진행률을 알려줄 방법이 **아예 없습니다**
- 이제 **바이트 단위로 진행률이 움직입니다.** 큰 파일만이 아니라 **항상** 보여줍니다
- **45초 동안 한 바이트도 안 올라가면** 끊고, 서버에 「어디까지 받았느냐」 물어
  **그 자리부터 이어 붙입니다**
- 사용량 초과·서버 오류(429·5xx)에는 **기다렸다 다시** 겁니다 (최대 6번)
- 아예 끊긴 상태면 **연결이 돌아올 때까지 기다렸다** 잇습니다
- 폰은 조각을 **2MB** 로 줄이고, 올리는 동안 **화면이 꺼지지 않게 붙잡습니다**

### 👀 보기 방식 3가지
목록 위 전환 버튼으로 고릅니다. 선택은 드라이브에 저장돼 다른 기기에서도 유지됩니다.

| | 쓰임새 |
|---|---|
| 📄 **나열** | 내용까지 펼쳐 보기. 훑어 읽을 때 |
| 🔲 **바둑판** | 카드를 격자로. 사진이 많을 때 한눈에 |
| ☰ **목록** | 제목만 한 줄씩 + 연결 수·첨부 수. 많이 쌓였을 때 찾기 |

### ☁️ 그 밖에
- 검색(제목·내용·태그·파일명), 유형별 필터
- 기록 편집·삭제 (삭제 시 폴더째 드라이브 휴지통으로)
- 설정도 드라이브에 저장(`PKEMS-settings.json`) → 다른 기기에서 로그인해도 내 유형·이름 규칙 그대로
- 전체 백업 JSON 내려받기 (`설정 → 고급`)
- 다크 모드 (기기 설정을 따라감)

**기본은 「기록마다 폴더 하나」** 입니다.

```
│   ├── 2026-08-16_물의 상태변화 수업_01.png     ← 사진
│   └── 2026-08-16_물의 상태변화 수업_02.pdf     ← 파일
├── 2026-08-17_지식_온도계 사용법/
│   └── 2026-08-17_지식_온도계 사용법.md

└── PKEMS-settings.json   ← 내 유형·이름 규칙·보기 설정
```

기록 하나가 폴더 하나라서 통째로 옮기거나 공유하기 쉽습니다.

`설정 → 저장 위치 → 폴더 정리 방식`에서 **5가지 중 고를 수 있고**, 고르면 그 자리에서
폴더 구조 미리보기가 나옵니다.

| 방식 | 결과 |
|---|---|
| **기록마다 폴더 하나** (기본) | `2026-08-16_경험_수업회고/` 안에 .md + 자료 |
| 글과 자료를 분리 | .md 는 맨 위, 사진·파일은 `자료/` 에 |
| 월별 폴더 | `2026-08/` 안에 그 달 전부 |
| **태그가 곧 폴더** | `수업설계/` 처럼 **태그 이름이 그대로 폴더**가 된다 |
| 한 폴더에 전부 | 나누지 않음 |

#### 🏷️ 태그가 곧 폴더

태그를 `수업설계, 3학년` 이라고 달면 이렇게 쌓입니다.

```
내 폴더/
├── 수업설계/                              ← 첫 태그가 진짜 자리
│   ├── 2026-08-16_경험_수업회고.md
│   └── 2026-08-16_수업회고_01.png
└── 3학년/
    └── 2026-08-16_경험_수업회고.md         ← 바로가기(표지판)
```

드라이브는 **파일 하나가 폴더 하나에만** 있을 수 있습니다 (2020년에 바뀌었습니다).
그래서 **첫 태그를 진짜 자리로 삼고, 나머지 태그 폴더에는 바로가기**를 놓습니다.
바로가기는 사본이 아니라 **표지판**이라 용량이 늘지 않고, 여러 번 저장해도 쌓이지 않습니다.
태그가 없으면 `태그없음/` 으로 갑니다.

바꾸면 **앞으로 저장되는 것부터** 적용됩니다. 이미 올라간 파일까지 옮기려면
같은 화면의 **「기존 파일도 새 방식으로 옮기기」** 를 누르세요 (드라이브에서 실제로 이동시킵니다).

## 7. 기술

| | |
|---|---|
| 구성 | 순수 HTML / CSS / JavaScript **단일 파일**, 빌드 도구·프레임워크·외부 라이브러리 없음 |
| 인증 | Google Identity Services (브라우저 토큰 방식, 클라이언트 시크릿 미사용) |
| 요청 범위 | `openid email https://www.googleapis.com/auth/drive` |
| 저장 | Google Drive REST API v3 — 글·색인은 multipart, 첨부는 **resumable** (PC 8MB · 폰 2MB 청크) |
| 업로드 | `XMLHttpRequest` (`fetch` 는 업로드 진행률을 못 냄) + 45초 정지 감지 + `bytes */total` 로 이어붙이기 + 429·5xx 지수 백오프 + `wakeLock` |
| 브라우저 저장 | `localStorage`(기록·설정·삭제기록·임시본·**토큰**) + `IndexedDB`(파일 본문 Blob) |
| 캡처 | `getDisplayMedia` → `<canvas>` 프레임 추출 → 드래그 영역만 잘라 재인코딩 |
| 웹캠 | `getUserMedia` → 미리보기 → 프레임 캡처 → 동일한 자르기 화면 |
| 모자이크 | 원본은 그대로 두고 **가린 자리 목록**만 들고 있다가 매번 다시 그림 (되돌리기가 공짜) |
| 손 메모 | `PointerEvent`(필압 포함) → 획을 점 목록으로 보관 → 1600×1100 로 다시 그려 저장 |
| 녹음 | `MediaRecorder`(1초 조각) + `AnalyserNode`(소리 막대) + `SpeechRecognition`(ko-KR, 끊기면 자동 재시작) |
| 웹 캡처 | manifest `share_target`(POST) → 서비스 워커가 받아 Cache Storage 에 두고 리다이렉트 · PC 는 북마클릿 `#capture=` |
| 폴더 지도 | 라이브러리 없이 자체 treemap(절반 나누기) — 절대배치 `<button>` 으로 그림 |
| 태그 폴더 | 첫 태그 = 실제 부모, 나머지 태그 = `google-apps.shortcut` (드라이브는 부모 하나만 허용) |
| 관계망 | 라이브러리 없이 `<canvas>` + 자체 힘기반 배치(척력·스프링·중심력·감쇠), 마우스/터치 공용 |
| 코드 삽입 | `srcdoc` + **sandbox iframe** (`allow-same-origin` 미부여로 앱과 격리) |
| 링크 미리보기 | 사이트 아이콘(구글 favicon 서비스) + 유튜브 썸네일. 남의 페이지 본문은 CORS 로 못 읽음 |
| 폴더 훑기 | 너비 우선 · 5단계 · 400곳 · 동시 4요청 상한 |

localStorage 키: `pkems.entries.v2`, `pkems.settings.v1`, `pkems.tombstones.v1`,
`pkems.draft.v1`, `pkems.folder`, `pkems.connected`, `pkems.token.v1`, `pkems.email`

> `pkems.token.v1` 은 **드라이브를 열 수 있는 열쇠**입니다. 만료시각까지만 유효하고
> 「연결 해제」를 누르면 지워집니다. 공용 컴퓨터에서는 쓰고 나서 꼭 눌러 주세요.

### 데이터 흐름
```
작성 → localStorage(글) + IndexedDB(파일)        ← 저장 안 눌러도 임시 보관
  ↓ [기록 저장]
기록별 폴더 확보 → 첨부 업로드(청크) → .md 업로드
  → 구글 문서/HTML 사본 → PKEMS-index.json 갱신
  ↓ 다른 기기
탭 복귀·포커스·온라인 복귀 시 색인을 다시 읽어 병합 (updatedAt 최신 우선, 삭제는 tombstone)
```

## 9. 개인정보

- 데이터는 **각 사용자의 구글 드라이브**에만 저장됩니다. 서버가 없어 만든 사람을 거치지 않습니다.
- 앱은 **지정된 폴더 안**만 읽고 씁니다.
- 접근 토큰은 **그 기기의 브라우저 안**에만 있고 (`pkems.token.v1`, 1시간짜리),
  「연결 해제」를 누르면 지워집니다. 만든 사람에게는 전달되지 않습니다.
- **받아쓰기를 켜면** 그동안의 소리가 브라우저를 통해 **구글 음성인식 서버**로 갑니다
  (구글 크롬의 기능입니다). 소리 파일 자체는 내 드라이브에만 저장됩니다.
- **「🔗 링크로 공유」를 누른 기록**은 그 순간부터 링크를 가진 누구나 읽을 수 있습니다.
  「공유 끄기」로 되돌릴 수 있지만, 이미 퍼진 링크는 되돌릴 수 없습니다.
- 연결 해제: [구글 계정 → 타사 앱 액세스](https://myaccount.google.com/permissions)
- 자세한 내용은 [privacy.html](privacy.html)
