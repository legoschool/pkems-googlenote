개인정보처리방침

PKEMS · 개인 지식·경험 기록장 (이하 "본 앱")

1. 본 앱의 성격

본 앱은 서버가 없는 정적 웹페이지입니다. 이용자가 작성한 기록과 첨부 자료는 운영자의 서버로 전송되거나 저장되지 않으며, 이용자 본인의 브라우저와 이용자 본인이 지정한 구글 드라이브 폴더에만 저장됩니다.

2. 저장되는 정보와 위치

정보저장 위치목적
기록(제목·내용·태그·링크·연결)브라우저 localStorage / 지정한 드라이브 폴더의 .md· 구글 문서기록 보관·조회
첨부 사진·영상·파일지정한 드라이브 폴더(올리기 전에는 브라우저 IndexedDB)자료 보관
작성 중이던 임시본브라우저 localStorage + IndexedDB창이 꺼져도 이어 쓰기
목록 색인·삭제 기록드라이브 폴더의 PKEMS-index.json기기 간 목록 동기화
구글 계정 이메일브라우저 메모리(화면 표시용)저장 계정 확인
설정값(폴더 ID·이름 규칙·보기 방식)브라우저 localStorage + 드라이브 PKEMS-settings.json다음 접속·다른 기기에서 재사용

운영자에게 전송되는 정보는 없습니다. 이 앱에는 서버가 없어, 모든 통신은 이용자의 브라우저와 구글 API 서버 사이에서만 직접 이루어집니다.

2-1. 이용자가 붙여넣은 삽입 코드

「코드 삽입」 기능으로 넣은 HTML(예: 유튜브 삽입 코드)은 격리된 틀(sandbox iframe) 안에서만 실행됩니다. 해당 코드는 이 앱의 기록 데이터나 로그인 정보에 접근할 수 없습니다. 다만 삽입한 외부 서비스(유튜브 등)는 그 서비스 자체의 개인정보처리방침에 따라 이용자 정보를 수집할 수 있습니다.

3. 구글 계정 접근 권한

본 앱은 구글 로그인 시 다음 권한을 요청합니다.

  • openid, email — 저장되는 계정을 화면에 표시하기 위함
  • https://www.googleapis.com/auth/drive — 이용자가 직접 입력한 폴더에 파일을 만들고 읽고 수정하기 위함

이용자가 임의의 폴더 ID·링크를 지정하는 기능 특성상 넓은 범위의 드라이브 권한이 필요합니다. 다만 본 앱은 지정된 폴더 안의 파일만 조회·생성·수정하며, 그 밖의 드라이브 파일을 열람하거나 외부로 전송하지 않습니다. 발급된 접근 토큰은 브라우저 메모리에만 존재하고 탭을 닫으면 사라집니다.

4. 제3자 제공 및 외부 전송

운영자는 이용자의 기록을 수집하지 않으므로 제3자에게 제공할 정보 자체가 없습니다. 통신은 이용자의 브라우저와 구글 API 서버 사이에서만 직접 이루어집니다. 광고·분석·추적 스크립트를 사용하지 않습니다.

5. 보관 기간과 삭제

  • 브라우저 저장분: 브라우저 데이터 삭제 또는 앱에서 기록 삭제 시 제거됩니다.
  • 드라이브 저장분: 앱에서 기록을 삭제하면 해당 기록 폴더(.md·구글 문서·첨부 자료)가 드라이브 휴지통으로 이동합니다. 완전 삭제는 드라이브 휴지통에서 하시면 됩니다.
  • 구글 계정 연결 해제: 구글 계정 → 보안 → 타사 앱 액세스에서 언제든 철회할 수 있습니다.

6. 문의

본 앱에 관한 문의는 앱을 배포한 운영자에게 연락하시기 바랍니다.
