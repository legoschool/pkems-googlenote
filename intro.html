글·사진·링크·목소리를 블로그처럼 이어 쓰고, 내 구글 드라이브 폴더에 마크다운으로 쌓아 두는 개인 기록 도구입니다.

왜 만들었나

2014년에 교단에 섰습니다. 그때부터 지금까지 수업을 하고, 아이들을 만나고, 실패하고, 다시 해 보고, 연수를 듣고, 자료를 만들었습니다. 그 12년이 지금 어디에 있는지 모릅니다.

흩어져 있어서 못 씁니다

드라이브 어느 폴더에, 옛 노트북 바탕화면에, 메신저 대화 어딘가에, 이름을 알 수 없는 최종_최종2_진짜최종.hwp 안에. 분명히 있는데 꺼낼 수가 없습니다. 쌓여만 있고 쓰이지 않는 것은, 없는 것과 그리 다르지 않습니다.

어떤 것은 아예 잃어버렸습니다

하드디스크가 조용히 죽었습니다. 잘 쓰던 서비스가 문을 닫았습니다. 학교를 옮기며 그 컴퓨터를 두고 왔습니다. 제가 아무것도 잘못하지 않았는데 사라진 것들이 있습니다. 남의 자리에 얹어 둔 기록은, 그 자리가 없어지면 같이 없어집니다.

AI에게 물어보고 싶은데, 건넬 수가 없습니다

「내가 3학년 과학을 지난 6년 동안 어떻게 가르쳐 왔지? 무엇이 안 됐고, 무엇을 바꿨더라?」 세상 누구도 대신 답해 줄 수 없는, 내 기록에만 있는 답입니다. 그런데 스크린샷 더미와 흩어진 파일로는 건넬 방법이 없습니다.

그래서 이렇게 정했습니다

정한 것왜
서버를 두지 않는다 한 번 잃어봤습니다. 만든 사람인 저조차 그 안을 볼 수 없어야 합니다
내 드라이브에 쌓는다 원본은 내가 가진다. 이 앱이 내일 없어져도 폴더를 열면 파일이 그대로 있습니다
끝은 언제나 마크다운 특정 앱을 켜야만 열리는 형식이면 그것도 결국 맡겨 두는 것입니다. 메모장으로도 열리게
파일 하나로 만든다 쓰는 사람이 열어서 직접 읽고 고칠 수 있는 크기로
되는 척하지 않는다 안 되는 것은 화면에 그대로 적습니다

무엇을 하나

아래 단추로 갈아 가며 보세요. 한 번에 한 가지씩만 나옵니다.

블록을 이어 붙여 한 편을 씁니다

한 번 입력하고 끝이 아닙니다. 글 → 사진 → 링크 → 소제목 → 파일 순서로 원하는 만큼 이어 붙입니다. 각 블록은 순서를 바꾸고 지울 수 있습니다.

쌓이면 이렇게 보입니다

사진 가리기 — 얼굴을 톡 눌러서

이 기록의 사진이 한 줄로 늘어섭니다. 얼굴 있는 사진만 골라 들어가 얼굴 위를 톡 누르면 동그랗게 지워집니다. 쓸어 넘기면 줄줄이 지워집니다.

가린 것은 올라가는 사진 자체에서 지워집니다. 미리보기만 가리는 게 아닙니다. 이미 드라이브에 올라간 사진도 같은 파일에 덮어써 고칠 수 있습니다.

웹 캡처 — 보던 것을 그 자리에서

폰에서는 공유 목록에 「구글 기록장」이 나타납니다. 인터넷·유튜브·사진첩 어디서든 「공유 → 구글 기록장」. 컴퓨터에서는 파란 딱지를 즐겨찾기 막대로 끌어다 놓으면 아무 웹페이지에서나 한 번에 담깁니다.

손 메모 — 자판 대신 손으로

손가락·마우스·태블릿 펜 모두 되고, 펜은 누르는 세기에 따라 굵기가 달라집니다. 칠판 앞에서, 회의 중에, 책 옆에서.

녹음 · 받아쓰기

말하면 그대로 받아 적힙니다. 키도 돈도 필요 없습니다. 소리 파일과 받아 적은 글이 함께 들어갑니다.

관계망 — 무엇이 무엇에서 나왔는지

글 속에 [[온도계 사용법]] 처럼 걸어 두면 기록끼리 이어집니다. 내가 아무것도 안 해도, 나를 가리킨 기록이 저절로 보입니다(백링크).

폴더 구조 — 드라이브가 지금 어떻게 생겼는지

탐색기처럼 위에서 아래로 펼쳐 봅니다. 지금 「폴더 정리 방식」 그대로 그리므로, 설정을 바꾸면 이 그림도 바뀝니다. 📝 를 누르면 그 기록이 열립니다.

여기서 📛 밖에서 넣은 파일 이름 정리 도 할 수 있습니다. 드라이브에 직접 넣은 IMG_4821.jpg 같은 자료 앞에 날짜와 폴더 이름을 붙여 줍니다. 12년치를 끌어올 때 쓰는 화면입니다.

전체 보기 · 링크로 공유

한 편을 종이처럼 펼쳐 읽고, 거기서 인쇄(PDF)·구글 문서·마크다운 원본·드라이브 폴더로 모두 이어집니다. 「🔗 링크로 공유」를 누르면 글 하나만 또는 폴더 통째로 고를 수 있고, 비공개인 것을 누르는 순간 「링크가 있는 사람 = 읽기」로 바꿔 줍니다.

🛡 공유 전 사진 확인 관문. 사진이 든 기록은 공유 단추가 처음엔 눌리지 않습니다. 그 기록의 사진이 전부 눈앞에 늘어서고, 「확인했습니다」를 체크해야 열립니다. 「가리는 걸 깜빡했다」가 되어서는 안 되니까요.

폰에서도 그대로

  • 자동 동기화 — 폰에서 쓰고 PC로 돌아오면 알아서 최신을 끌어옵니다
  • 삭제도 전파 — 폰에서 지운 기록이 PC에서 되살아나지 않습니다
  • 비행기 모드에서 써 두고 나중에 연결해도 그대로 올라갑니다
  • 업로드가 멈추지 않습니다 — 진행률이 초 단위로 움직이고, 끊기면 받은 자리부터 다시 잇습니다
  • 새로고침해도 로그인이 안 풀립니다 — 풀리면 「다시 연결」 한 번

시작하는 법

길이 두 가지입니다. 받는 사람이냐, 나눠 주는 사람이냐에 따라 다릅니다.

🅐 링크를 받았다면 — 2분

  1. 링크를 열고 «구글 로그인»

    「Google에서 확인하지 않은 앱」 경고가 뜹니다. 정상입니다. 개인·학교가 만든 앱은 모두 그렇습니다. [고급] → [이동] 을 누르세요. 이 경고를 모르면 대부분 여기서 멈춥니다.

  2. 저장할 드라이브 폴더를 한 번만 지정

    구글 드라이브에서 폴더를 하나 만들고, 그 폴더를 연 상태의 주소창 링크를 복사해 붙여넣습니다. 「이 폴더로 연결」을 누르면 끝입니다.

  3. 그다음부터는 쓰기만 하면 됩니다

    연결 전에 쓴 글도 브라우저에 보관됐다가 연결하는 순간 한꺼번에 올라갑니다.

  4. 폰이라면 «홈 화면에 추가»

    앱으로 설치해야 공유 목록에 「구글 기록장」이 나타납니다. 웹 캡처를 쓰려면 이 단계가 필요합니다.

🅑 내 사본을 만든다면 — 10분

이 앱은 구글 심사를 받지 않은 상태라 한 프로젝트당 평생 100명만 로그인할 수 있습니다. 사본마다 100명이 새로 생깁니다. 연수나 학교 단위로 나눠 줄 계획이면 사본을 뜨세요.

  1. GitHub 저장소를 하나 만들고 파일을 올립니다

    GitHub Pages 를 켜면 내계정.github.io/저장소이름/ 으로 열립니다.

  2. 구글 클라우드에서 클라이언트 ID 를 발급받습니다

    「승인된 자바스크립트 원본」에 내 주소 앞부분만 (경로 없이) 넣습니다. 요청 권한은 openid, userinfo.email, drive 세 가지입니다.

  3. index.html 맨 위의 OWNER_CLIENT_ID 를 내 것으로 바꿉니다

    클라이언트 ID 는 비밀번호가 아니라 공개용 식별자라 코드에 있어도 안전합니다.

🚚 캡처 36장으로 클릭 순서까지 적어 둔 전체 안내가 저장소의 SETUP.md 에 있습니다. GitHub 저장소에서 열면 그림까지 그대로 보입니다.

⚠️ 이 페이지 주소를 공개 게시판에 올리지 마세요. 위의 「기록장 열기」가 이 사본의 100명 자리로 들어오는 문입니다. 한 번 쓴 자리는 되돌릴 수 없습니다. 나눠 줄 사람에게만 주소를 주세요.

드라이브에 쌓이는 모습

앱이 사라져도 남는 것은 이 파일들입니다. 폴더를 열면 그냥 보통 파일이 있습니다.

내가 지정한 폴더/
├── 2026-08-17_수업설계_물의 상태변화 수업/
│   ├── 2026-08-17_수업설계_물의 상태변화 수업.md   ← 글 (옵시디언·AI 용)
│   ├── 2026-08-17_수업설계_물의 상태변화 수업      ← 구글 문서 (사람이 읽는 용)
│   ├── 2026-08-17_수업설계_물의 상태변화 수업_칠판 정리_01.jpg
│   └── 2026-08-17_수업설계_물의 상태변화 수업_학습지_02.pdf
├── 2026-08-14_수업설계_온도계 바르게 읽는 법/
│   └── 2026-08-14_수업설계_온도계 바르게 읽는 법.md
├── TRACE-index.json      ← 앱 목록 색인
└── TRACE-settings.json   ← 내 유형·이름 규칙·보기 설정

파일 이름은 기본이 날짜 + 태그 + 제목 + 자료 제목 + 번호 입니다. 사진마다 제목을 적으면 그것이 이름에 들어갑니다. 규칙은 직접 조립할 수 있습니다.

폴더가 나뉘는 방식은 5가지 중에 고릅니다 — 기록마다 폴더 하나 / 글과 자료를 분리 / 월별 폴더 / 태그가 곧 폴더 / 한 폴더에 전부.

옵시디언에서 그대로 열립니다. 구글 드라이브 데스크톱 앱으로 폴더를 동기화한 뒤 「폴더를 볼트로 열기」 하면 링크·백링크·그래프 뷰가 바로 동작합니다.

알아둘 점

되는 척하는 기능이 안 되는 기능보다 위험합니다. 그래서 적어 둡니다.

항목내용
인원심사 전이라 한 프로젝트당 100명(평생) 한도. 사본을 뜨면 100명이 새로 생깁니다
파일 크기하나당 200MB. 긴 영상은 유튜브에 「일부공개」로 올리고 ＋코드 삽입 에 주소를
얼굴 자동 인식없습니다. 브라우저에 그 기능이 사실상 없고, 외부 모델을 붙여도 옆모습·뒷줄을 자주 놓칩니다. 「자동으로 가려 준다」를 믿게 만들어 놓고 놓치는 것이 더 위험합니다
백그라운드 녹음다른 앱으로 넘어가거나 화면이 꺼지면 브라우저가 마이크를 놓습니다. 웹앱으로는 못 넘는 벽입니다
손글씨 인식넣지 않았습니다. 외부 AI 키가 필요해지면 「링크 열고 로그인」 두 단계인 진입 문턱이 확 올라갑니다
HTML 공유드라이브가 HTML 을 웹페이지로 열어주지 않습니다 (2016년에 없어진 기능). 사람에게 보여줄 것은 구글 문서 쪽입니다
아이폰 공유 시트사파리가 지원하지 않습니다. 주소를 복사해 붙여넣거나 사진첩에서 골라 넣으세요
실행 환경캡처·녹음·로그인은 https:// 또는 localhost 에서만. file:// 로 열면 막힙니다
외부 편집드라이브의 .md 를 직접 고치거나 이름을 바꾸면 색인과 어긋납니다. 읽기·탐색은 옵시디언, 편집은 앱으로 나누는 게 안전합니다
🔒 개인정보. 데이터는 각 사용자의 구글 드라이브에만 저장됩니다. 서버가 없어 만든 사람을 거치지 않습니다. 앱은 지정된 폴더 안만 읽고 씁니다. 연결 해제는 구글 계정 → 타사 앱 액세스 에서. 자세한 내용은 개인정보처리방침.

trace 는 두 가지 뜻입니다.
흔적을 남기다 — 기록하는 일.
흔적을 따라가다 — 그것을 쓰는 일.

구글 기록장은 그 체계를 쓰는 도구의 이름입니다.
