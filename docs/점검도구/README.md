# 화면 점검 도구 (고치는 사람용)

**앱을 쓰는 데는 필요 없습니다.** `index.html` 을 고친 뒤 **정말로 동작하는지**
사람이 일일이 눌러 보지 않고 확인하는 도구입니다.

브라우저를 화면 없이 띄워 놓고 진짜로 눌러 봅니다 — 사진을 넣고, 모자이크를 칠하고,
펜으로 획을 긋고, 녹음을 켜고, 공유를 보내 봅니다. 그리고 **결과를 픽셀 단위로 확인**합니다.

## 쓰는 법

```bash
node docs/점검도구/화면점검.mjs http://localhost:8000/
```

앱을 먼저 띄워 두어야 합니다.

```bash
powershell -ExecutionPolicy Bypass -File docs/점검도구/띄우기.ps1
```

| 파일 | 하는 일 |
|---|---|
| `띄우기.ps1` | 저장소를 `http://localhost:8000` 으로 띄운다 (파이썬·노드 서버 없이) |
| `화면점검.mjs` | **새로 만든 기능**을 눌러 보고 픽셀까지 확인한다 (61가지) |
| `구석구석.mjs` | **원래 있던 화면**을 전부 열어 본다 — 관계망·엮어내기·설정 5칸·보기 3종·검색·삭제·다크모드·좁은 화면 (26가지) |
| `이름바꾸기.mjs` | **옛 이름(PKEMS·PEER)으로 쌓아 둔 것이 TRACE 에서 그대로 이어지는지** (11가지) |
| `공유쪽.mjs` | **웹 쪽으로 공유한 링크가 펴지는지** — 영상·녹음 재생기 · 사진 대비책 · 잘린 주소 (16가지) |
| `소개페이지.mjs` | 소개 페이지(`intro.html`)가 **쪽으로 제대로 갈리는지** — 한 번에 한 쪽만 · 맨 위로 · 주소로 바로 열기 (27가지) |
| `자료가져오기.mjs` | **폴더를 훑어 글·자료를 색인에 넣는 길** — 가짜 드라이브를 세워 로그인 없이 끝까지. 가져온 «뒤» 고치기·빼기·지우기·길찾기 줄·폴더 찾아보기·목록 디렉토리까지 (52가지) |

```bash
node docs/점검도구/화면점검.mjs http://localhost:8000/
node docs/점검도구/구석구석.mjs http://localhost:8000/
node docs/점검도구/이름바꾸기.mjs http://localhost:8000/
node docs/점검도구/자료가져오기.mjs http://localhost:8000/
node docs/점검도구/공유쪽.mjs     http://localhost:8000/
node docs/점검도구/소개페이지.mjs   http://localhost:8000/intro.html <캡처를 넣을 폴더>
```

> ⚠️ `소개페이지.mjs` 는 **두 번째 인자(캡처를 넣을 폴더)** 가 있어야 합니다. 빼먹으면 죽습니다.

> ⚠️ **먼저 돌린 브라우저가 남아 있으면 다음 점검이 엉뚱하게 실패합니다.**
> 점검 도구는 저마다 정해진 포트(9333·9345·9351…)로 브라우저를 띄웁니다.
> 앞선 것이 안 죽고 남아 있으면 새로 띄운 것이 그 포트를 못 잡고,
> 대신 **죽어 가는 옛 창에 붙어** 「＋버튼 0개」 같은 헛된 실패가 납니다.
> 코드 결함이 아닙니다. 이럴 때는 먼저 치우고 다시 도세요.
>
> ```powershell
> Get-CimInstance Win32_Process -Filter "Name='msedge.exe'" |
>   Where-Object { $_.CommandLine -like '*remote-debugging-port=93*' } |
>   ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
> ```

> ⚠️ **`이름바꾸기.mjs` 는 저장 키를 건드리는 코드를 고칠 때마다 돌리세요.**
> 이게 깨지면 쓰던 사람의 기록이 «없는 것»이 됩니다. 화면 오류가 아니라 **자료 사고**입니다.

## 필요한 것

- **노드(node)** — 설치돼 있어야 합니다. `node -v` 로 확인
- **엣지 또는 크롬** — 둘 중 아무거나

설치할 꾸러미(npm install)는 **없습니다.** 노드 24 에 들어 있는 것만 씁니다.

## 확인하는 것

| 묶음 | 보는 것 |
|---|---|
| 첫 화면 | 그려지는가 · 자바스크립트 오류가 없는가 |
| 사진 모자이크 | 가린 쪽 픽셀이 **실제로** 뭉개졌는가 · 안 가린 쪽은 **한 점도** 안 바뀌었는가 |
| 손 메모 | 펜 획이 종이에 남는가 · 되돌리기가 켜지는가 · 사진 블록이 되는가 |
| 녹음 | 시계가 도는가 · 소리 크기 막대가 움직이는가 · 소리가 담기는가 |
| 웹 캡처 | 즐겨찾기 한 줄이 만들어지는가 · 주소·글이 블록이 되는가 |
| 공유 시트 | 서비스 워커가 POST 를 받는가 · 사진까지 넘어오는가 |
| 폴더 지도 | 태그마다 덩어리가 생기는가 · 빈틈없이 채우는가 · 눌러서 걸러지는가 |
| 녹음 | 제목 칸이 따로 있는가 · 받아 적은 글이 «자료 제목» 으로 새지 않는가 |
| 폴더 정리 방식 | 다섯이 한눈에 펼쳐지는가 · select 가 그림을 덮지 않는가 · 폴더 그림이 붙는가 |
| 폴더 찾아보기 | 내 드라이브를 여는가 · 눌러 들어가는가 · 맨 위는 막는가 |
| 목록 = 디렉토리 | 폴더로 갈리는가 · 최신 것부터인가 · 접히는가 |
| 모양 프리셋 | 처음에 묻는가 · 고르면 그 자리에서 토큰이 바뀌는가 · 유형마다 색이 다른가 |
| 길찾기 줄 | 「내 폴더 › 2019 › 3학년 › 과학」 이 서는가 · 눌러서 그 아래로 좁혀지는가 |
| 자료 끌어오기 | 한글·발표·PDF·사진·구글 문서가 기록으로 서는가 · 폴더 이름이 태그가 되는가 · **또 눌러도 안 불어나는가** |
| 원본 안전 | 고치고·빼고·지워도 **원본을 안 버리고 안 옮기고 이름도 안 바꾸는가** — 요청 단위로 지켜본다 |

## 알아둘 점

- **마이크가 없어도 녹음을 시험합니다.** `--use-fake-device-for-media-stream` 으로
  가짜 마이크를 붙입니다.
- **받아쓰기는 시험하지 못합니다.** 구글 음성인식 서버에 붙어야 해서, 화면 없는
  브라우저로는 확인이 안 됩니다. **실제 기기에서 한 번은 직접 말해 봐야 합니다.**
- **드라이브에 실제로 «올리는» 것은 시험하지 못합니다.** 로그인이 필요합니다.
  다만 **«끌어오는» 쪽은 `자료가져오기.mjs` 로 끝까지 봅니다** — 페이지가 뜨기 전에
  `window.fetch` 를 갈아 끼워 «가짜 드라이브» 를 앞에 세웁니다. 계정이 없어도
  폴더 나무·쪽 나누기·바로가기·부스러기까지 그대로 겪게 만들 수 있습니다.
  그래도 **색인에 무엇이 들어오는가** 까지입니다. 드라이브에 실제로 무엇이 쌓이는지는 아닙니다.
- 잔무늬 그림으로 모자이크를 시험합니다. 줄무늬로 하면 칸 크기와 줄 간격이 맞아떨어져
  뭉갠 티가 안 나서 판정이 흐려집니다.

## 문법만 빠르게 보고 싶으면

```bash
node -e "const fs=require('fs');const h=fs.readFileSync('index.html','utf8');const i=h.indexOf('<script>');const j=h.lastIndexOf('</script>');fs.writeFileSync('app.js',h.slice(i+8,j))" && node --check app.js
```
