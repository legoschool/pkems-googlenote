# 화면 점검 도구 (고치는 사람용)

**앱을 쓰는 데는 필요 없습니다.** `index.html` 을 고친 뒤 **정말로 동작하는지**
사람이 일일이 눌러 보지 않고 확인하는 도구입니다.

브라우저를 화면 없이 띄워 놓고 진짜로 눌러 봅니다 — 사진을 넣고, 모자이크를 칠하고,
펜으로 획을 긋고, 녹음을 켜고, 공유를 보내 봅니다. 그리고 **결과를 픽셀 단위로 확인**합니다.

## 쓰는 법

```bash
node docs/점검도구/화면점검.mjs http://localhost:8000/
```

앱을 먼저 띄워 두어야 합니다.

```bash
powershell -ExecutionPolicy Bypass -File docs/점검도구/띄우기.ps1
```

| 파일 | 하는 일 |
|---|---|
| `띄우기.ps1` | 저장소를 `http://localhost:8000` 으로 띄운다 (파이썬·노드 서버 없이) |
| `화면점검.mjs` | 엣지(또는 크롬)를 화면 없이 띄워 43가지를 눌러 보고 결과를 확인한다 |

## 필요한 것

- **노드(node)** — 설치돼 있어야 합니다. `node -v` 로 확인
- **엣지 또는 크롬** — 둘 중 아무거나

설치할 꾸러미(npm install)는 **없습니다.** 노드 24 에 들어 있는 것만 씁니다.

## 확인하는 것

| 묶음 | 보는 것 |
|---|---|
| 첫 화면 | 그려지는가 · 자바스크립트 오류가 없는가 |
| 사진 모자이크 | 가린 쪽 픽셀이 **실제로** 뭉개졌는가 · 안 가린 쪽은 **한 점도** 안 바뀌었는가 |
| 손 메모 | 펜 획이 종이에 남는가 · 되돌리기가 켜지는가 · 사진 블록이 되는가 |
| 녹음 | 시계가 도는가 · 소리 크기 막대가 움직이는가 · 소리가 담기는가 |
| 웹 캡처 | 즐겨찾기 한 줄이 만들어지는가 · 주소·글이 블록이 되는가 |
| 공유 시트 | 서비스 워커가 POST 를 받는가 · 사진까지 넘어오는가 |
| 폴더 지도 | 태그마다 덩어리가 생기는가 · 빈틈없이 채우는가 · 눌러서 걸러지는가 |

## 알아둘 점

- **마이크가 없어도 녹음을 시험합니다.** `--use-fake-device-for-media-stream` 으로
  가짜 마이크를 붙입니다.
- **받아쓰기는 시험하지 못합니다.** 구글 음성인식 서버에 붙어야 해서, 화면 없는
  브라우저로는 확인이 안 됩니다. **실제 기기에서 한 번은 직접 말해 봐야 합니다.**
- **드라이브에 실제로 올리는 것도 시험하지 못합니다.** 로그인이 필요합니다.
- 잔무늬 그림으로 모자이크를 시험합니다. 줄무늬로 하면 칸 크기와 줄 간격이 맞아떨어져
  뭉갠 티가 안 나서 판정이 흐려집니다.

## 문법만 빠르게 보고 싶으면

```bash
node -e "const fs=require('fs');const h=fs.readFileSync('index.html','utf8');const i=h.indexOf('<script>');const j=h.lastIndexOf('</script>');fs.writeFileSync('app.js',h.slice(i+8,j))" && node --check app.js
```
