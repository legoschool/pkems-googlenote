## ⚠️ 찍기 전에 가려야 할 것

이 저장소는 **공개(Public)** 입니다. 캡처에 아래가 들어가지 않게 해주세요.

| 가릴 것 | 왜 |
|---|---|
| **클라이언트 보안 비밀번호** | 유출되면 안 됩니다 (12번 캡처 주의) |
| 계정 이메일 · 프로필 사진 | 개인정보. 콘솔 오른쪽 위에 항상 떠 있습니다 |

| 드라이브 폴더 안의 실제 기록 제목 | 개인 기록 노출 |

**필요한 부분만 잘라서** 찍으면 대부분 해결됩니다.
가리기 어려우면 그 부분만 검은 사각형으로 덮어 주세요.
