# 캡처 도구 (안내서 만드는 사람용)

**앱을 쓰는 데는 필요 없습니다.** `SETUP.md` 의 안내 그림을 다시 찍을 때만 쓰는 스크립트입니다.

`docs/작업이어가기.md` 의 「캡처 도구」 항목에 쓰는 순서와 주의할 점이 적혀 있습니다.
그쪽을 먼저 읽으세요.

| 파일 | 하는 일 |
|---|---|
| `movewin.ps1` | 크롬 창을 정해진 크기(2000x1450)로 고정 |
| `shotbox.ps1` | 화면을 찍고 붉은 네모·검은 가림을 그림 |
| `click.ps1` | 브라우저 UI(탭·안내 띠)를 진짜 마우스로 클릭 |
| `key.ps1` | 크롬 단축키 보내기 (`^+b` = 북마크바 토글) |
| `boxpng.ps1` | 이미 찍은 png 위에 네모를 다시 그림 |
| `rect.js` | 페이지 요소의 화면 좌표를 구하는 도우미 |

> 좌표는 **창을 2000x1450 으로 고정하고 북마크바를 숨긴 상태** 기준입니다.
> 창 크기를 바꾸면 `docs/작업이어가기.md` 에 적힌 고정 오프셋(13, 172)도 다시 재야 합니다.
