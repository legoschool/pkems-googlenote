#### ✅ 캡처를 파일로 저장하기 — 해결됨 (2026-08-16)

| 방법 | 결과 |
|---|---|
| `mcp__Claude_Browser__*` | ❌ `save_to_disk` 옵션 자체가 없음 |
| `mcp__claude-in-chrome__*` + `save_to_disk: true` | ❌ **쓰지 마세요.** 이 노트북 크롬(`구글 메모장`)을 직접 연결해 찍어도 C·D 드라이브 어디에도 파일이 안 생깁니다. 지난 세션의 「데스크톱에 저장됐나 보다」는 오해였고, 그냥 안 되는 것입니다 |
| **PowerShell 화면 캡처** | ✅ **이게 됩니다** |

**되는 방법 — .NET `CopyFromScreen` 으로 노트북 화면을 직접 찍습니다.**

```powershell
Add-Type '...[DllImport("user32.dll")] public static extern bool SetProcessDPIAware();...'
[void][DpiHelper]::SetProcessDPIAware()      # ← 이거 빼면 화면 왼쪽 위 1/4 만 찍힘
$vs  = [System.Windows.Forms.SystemInformation]::VirtualScreen
$bmp = New-Object System.Drawing.Bitmap($W, $H)
[System.Drawing.Graphics]::FromImage($bmp).CopyFromScreen($X, $Y, 0, 0, $bmp.Size)
$bmp.Save($Out, [System.Drawing.Imaging.ImageFormat]::Png)
```

- 이 노트북 화면은 **2560x1600**. `SetProcessDPIAware()` 를 먼저 부르지 않으면
  `VirtualScreen` 이 1280x800 으로 나와 **왼쪽 위 귀퉁이만** 찍힙니다 (겪은 문제)
- `-X -Y -W -H` 로 영역을 잘라 찍을 수 있음 → 계정 이메일·다른 창을 애초에 안 찍는 게 제일 안전
- 전체 스크립트를 세션 스크래치패드에 `shot.ps1` 로 만들어 썼습니다. 짧으니 새로 만들어 쓰세요

**⚠️ 이 방식의 성격 — 브라우저가 아니라 「지금 노트북 화면」을 찍습니다.**
찍기 전에 **크롬 창을 맨 앞으로 올려야** 하고, 화면에 떠 있는 다른 것(구글 미트 창,
카톡, 다른 문서)이 **그대로 같이 찍힙니다.** 저장소가 공개라 특히 조심해야 합니다.
실제로 첫 시험 캡처에 **미트 참가자 얼굴·이름 30여 명**이 통째로 들어왔습니다.

## 아직 실제 환경에서 확인 못 한 것

코드는 검증했지만 **실제 구글 드라이브 왕복은 못 해봤습니다.** 사용자에게 확인 요청하거나 같이 확인할 것.

1. **기록별 폴더 생성** — `설정 → 저장 위치` 기본값이 「기록마다 폴더 하나」.
   저장 시 폴더가 만들어지고 그 안에 `.md` + 자료가 들어가는지
2. **200MB 조각 업로드(resumable)** — 6MB 넘는 파일 업로드 시 진행률(`↑ 파일명… 42%`)과 완료.
   `Location` 헤더를 못 읽으면 25MB 이하는 옛 방식으로 자동 재시도하게 해뒀음
3. **구글 문서 사본 생성** — 기본 켜짐. 카드 → `👁 전체 보기` 위쪽에 `📄 구글 문서` 버튼이 뜨는지
4. **폴더 훑어서 가져오기** — 옵시디언 등으로 만든 `.md` 를 실제로 편입하는지
   (파싱 로직은 단위 검증 완료. 훑기는 **연결 폴더 아래 5단계·400곳** 까지 —
   깊이·상한 동작은 가짜 트리로 검증했고, 실제 드라이브 왕복은 아직)

> ⚠️ `PKEMS-index.json` 과 `PKEMS-settings.json` 은 **연결 폴더 바로 아래**에 있어야 합니다.
> 이름으로 그 폴더 안에서만 찾기 때문에(`findInFolder`), 하위 폴더로 내리면
> 색인을 못 찾고 빈 것을 새로 만듭니다. 자료 파일은 어디로 옮겨도 파일 ID 로 찾습니다.

## 앱 구조 요약 (코드 읽기 전에)

`index.html` 단일 파일. 주석으로 섹션이 번호로 나뉘어 있습니다.

```
0    소유자 설정 (OWNER_CLIENT_ID, SCOPE, DEFAULTS, FOLDER_MODES, VIEW_MODES)
1    유틸           2  상태/localStorage/IndexedDB/임시저장
3    구글 인증      4  드라이브 폴더(기록별 폴더·이동)  5  파일 이름 규칙
5-2  위키링크/백링크/relations
6    마크다운·HTML·구글문서 생성
7    동기화(syncPending, 색인, tombstone)
8    블록 에디터    8-9 임시저장(draft)
9    저장/편집     10  목록 렌더(보기 3종·슬라이드·영상)
11-8 폴더에서 가져오기   11-9 웹 클리퍼
12-0 도움말   12-1 관계망   12  설정 모달
13   이벤트   14  시작
```

### 알아둘 설계 결정

- **첨부는 Blob 으로 들고 IndexedDB 에 보관** (base64 아님). localStorage 에는 절대 넣지 않음
  → 블록 복사는 반드시 `cloneBlock()` 사용. `JSON.parse(JSON.stringify())` 쓰면 **Blob 이 뭉개짐**(과거 버그)
- **삭제는 tombstone** 으로 전파. 색인의 `deleted` 배열
- **관계는 두 종류** — 글 속 `[[링크]]` 와 `relations[]`(관계망에서 만든 것, 설명 붙음). `linkData()` 에서 합침
- **코드 삽입은 sandbox iframe**, `allow-same-origin` 절대 주지 말 것
- 캔버스(관계망)는 **매 프레임 크기 동기화** 필요 — 안 하면 클릭 좌표가 어긋남(과거 버그)

## 로컬에서 띄우는 법

`http://localhost:8000` 이 OAuth 승인된 원본이라 로그인까지 테스트 가능합니다.

```
서버 스크립트: (스크래치패드)\serve.ps1   ← PowerShell TcpListener, 8000 포트
서비스 폴더:   (스크래치패드)\site\        ← index.html 을 여기로 복사해서 테스트
```

이 노트북에는 **python·node·gh CLI 가 없습니다.** git 은 있고 GitHub 자격증명도 저장돼 있습니다.

> 스크래치패드 경로는 세션마다 바뀝니다. 새로 만들어 쓰세요.
> 한글 경로를 PowerShell 스크립트 안에 상수로 넣으면 인코딩이 깨집니다 — 겪었던 문제입니다.

### 커밋할 때

커밋 메시지에 `->` 를 쓰면 PowerShell 이 git 인자로 잘못 넘겨 실패합니다.
**메시지는 파일로 만들어 `git commit -F 파일` 로** 하세요.
