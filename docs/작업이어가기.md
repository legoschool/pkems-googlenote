## 캡처 도구 — 이게 핵심입니다

브라우저 확장의 `save_to_disk` 는 **파일을 안 만듭니다**(확인 완료, 쓰지 마세요).
**PowerShell 로 화면을 직접 찍고 그 위에 붉은 네모를 그립니다.**

### ① 좌표 구하기 — 페이지에 넣는 도우미

```js
// 요소의 «화면 좌표(물리 픽셀)» 를 구한다
const dpr = () => devicePixelRatio;
const offX = () => (window.screenX + (outerWidth - innerWidth) / 2) * dpr();
const offY = () => (window.screenY + (outerHeight - innerHeight)) * dpr();
window.__scr = (r, pad) => [ Math.round((r.left-pad)*dpr()+offX()), Math.round((r.top-pad)*dpr()+offY()),
                             Math.round((r.width+pad*2)*dpr()), Math.round((r.height+pad*2)*dpr()) ].join(',');
window.__r = (sel, pad) => __scr(document.querySelector(sel).getBoundingClientRect(), pad ?? 6);
window.__t = (txt) => { /* 버튼 «글자» 로 찾기 — 가장 안쪽 요소 */ };
window.__crop = (l,t,r,b) => `-X .. -Y .. -W .. -H ..`;   // 자를 영역
```

전체본을 세션 스크래치패드에 `rect.js` 로 만들어 뒀었습니다. 짧으니 새로 만들어 쓰세요.

### ② 찍고 네모 그리기 — `shotbox.ps1`

```powershell
shotbox.ps1 -Out 파일.png -X .. -Y .. -W .. -H .. `
            -Front "창 제목 일부" `
            -Boxes "x,y,w,h;x,y,w,h" `   # 붉은 네모 (화면 좌표)
            -Hide  "x,y,w,h"             # 검게 덮기 (개인정보)
```

- `SetProcessDPIAware()` **먼저 부를 것.** 안 하면 화면 왼쪽 위 1/4 만 찍힙니다 (이 노트북 2560x1600)
- 붉은 색 `Color.FromArgb(255,230,30,45)`, 굵기 5, `PenAlignment.Inset`

## 고친 진짜 결함 4가지 (재발 주의)

1. **조각 업로드에 토큰 갱신이 없었음** — 창을 오래 켜 두면 401 로 첨부 업로드가 끊겼다.
   `putChunks` 에 401/403 재시도 추가. (「업로드 실패: [object ProgressEvent]」의 뿌리)
2. **오류 메시지가 원인을 덮음** — base64 재시도 실패(ProgressEvent)가 처음 오류를 가렸다. `errText()` 로 정리.
3. **사진 창이 전체 보기 뒤에 깔림** — 라이트박스 `z-index:130` < 전체 보기 `140`. **160 으로 올림.**
   “사진 크게 보기가 안 된다”의 원인.
4. **썸네일 6장 제한** — 카드당 6장까지만 불러와 나머지가 **영영 빈 칸**이었다.
   제한을 없애고 `IntersectionObserver` 로 화면에 들어올 때 불러온다.

## 앱 구조 요약 (코드 읽기 전에)

`index.html` 단일 파일. 주석으로 섹션이 번호로 나뉩니다.

```
0    소유자 설정 (OWNER_CLIENT_ID, SCOPE, DEFAULTS, FOLDER_MODES, VIEW_MODES)
1    유틸           2  상태/localStorage/IndexedDB/임시저장
3    구글 인증      4  드라이브 폴더  5  파일 이름 규칙
5-2  위키링크/백링크/relations
6    마크다운·HTML 생성 (blocksToMarkdown / blocksToHtml / htmlPage)
7    동기화(syncPending, 색인, tombstone)
8    블록 에디터    8-9 임시저장(draft)
9    저장/편집     10  목록 렌더(보기 3종·슬라이드·영상)
10-2 엮어내기 (compileMarkdown / compileHtml / widenByLinks)
11-8 폴더에서 가져오기 (5단계까지 훑음)
12-0 도움말   12-1 관계망   12  설정 모달
13   이벤트   14  시작
```

### 알아둘 설계 결정

- **첨부는 Blob 으로 들고 IndexedDB 에 보관**. localStorage 에는 절대 넣지 않음
  → 블록 복사는 반드시 `cloneBlock()`. `JSON.parse(JSON.stringify())` 쓰면 **Blob 이 뭉개짐**
- **삭제는 tombstone** 으로 전파
- **관계는 두 종류** — 글 속 `[[링크]]` 와 `relations[]`. `linkData()` 에서 합침
- **코드 삽입은 sandbox iframe**, `allow-same-origin` 절대 주지 말 것
- 캔버스(관계망)는 **매 프레임 크기 동기화** 필요
- **블록→마크다운/HTML 은 함수로 분리돼 있음**(`blocksToMarkdown(n, h)` / `blocksToHtml(n, h)`).
  한 편 뽑기와 여러 편 엮기가 같은 코드를 씁니다. 소제목 단계(`h`)만 다름
- **날짜만 뽑을 때는 `localDay()`** 를 쓸 것. `createdAt.slice(0,10)` 은 UTC 라 하루 어긋남

## 로컬에서 띄우는 법

`http://localhost:8000` 이 OAuth 승인된 원본이라 로그인까지 테스트 가능합니다.

```
서버 스크립트: (스크래치패드)\serve.ps1   ← HttpListener, 8000 포트
서비스 폴더:   (스크래치패드)\site\        ← index.html 을 복사해서 테스트
.claude/launch.json 의 경로도 새 스크래치패드로 바꿔야 preview_start 가 됩니다
```

이 노트북에는 **python·node·gh CLI 가 없습니다.** git 은 있고 GitHub 자격증명도 저장돼 있습니다.

> 스크래치패드 경로는 세션마다 바뀝니다.
> 한글 경로를 PowerShell 스크립트 안에 상수로 넣으면 인코딩이 깨집니다.

### 커밋할 때

- 커밋 메시지에 `->` 를 쓰면 PowerShell 이 git 인자로 잘못 넘겨 실패합니다.
  **메시지는 파일로 만들어 `git commit -F 파일`**
- `Out-File -Encoding utf8` 은 **BOM 을 붙여** 커밋 제목 앞에 깨진 글자가 들어갑니다.
  `[System.IO.File]::WriteAllText($p, $t, (New-Object System.Text.UTF8Encoding($false)))` 를 쓰세요
- `D:\구글 기록장\...` 경로에 `Remove-Item` 을 쓰면 보호 규칙에 막힙니다. `git rm` 도 같은 이유로 막힘
