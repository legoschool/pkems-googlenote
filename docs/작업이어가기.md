## ⚠️ v5 에서 알아낸 것 — 다음 사람이 꼭 알아야 할 두 가지

### 1. 구글 토큰 창은 «조용히» 열 수 없다

`google.accounts.oauth2` 에는 **«조용히 받기» 라는 길이 없습니다.** 부르면 **무조건 팝업**입니다.
사용자가 아무것도 안 누른 상태(예: 페이지 로드 직후)에서 부르면 브라우저가
「내가 안 시킨 창」으로 보고 **막습니다.** 그리고 예전 코드는 그 실패를
`.catch(function(){})` 로 삼켰습니다 — **이것이 「폰에서 로그인이 풀린다」의 진짜 정체입니다.**

지금은 이렇게 합니다.
- 토큰을 **만료시각과 함께 `localStorage`** 에 둔다 (`pkems.token.v1`). 살아 있으면 그대로 쓴다
- `canOpenPopup()` — **최근 60초 안에 누른 적이 있을 때만** 토큰 창을 연다
- 못 열면 조용히 넘어가지 않고 `needReconnect = true` → **「다시 연결」 띠**

> 이 사실을 모르고 「startup 에서 조용히 갱신하자」고 고치면 **원래 버그로 되돌아갑니다.**

### 2. `fetch` 로는 업로드 진행률을 못 낸다

`fetch()` 에는 **업로드 진행 이벤트가 아예 없습니다.** 그래서 예전에는 조각(8MB) 하나가
끝나야 진행률이 움직였고, 폰에서 그건 **20~60초 동안 `0%` 에 붙어 있는 것**이었습니다.
사용자가 말한 「멈춘 채로 있어」가 이것이었습니다.

지금은 `XMLHttpRequest` + `xhr.upload.onprogress` 입니다. 되돌리지 마세요.
함께 들어간 것: **45초 정지 감지**(`STALL_MS`) → 끊고 `bytes */total` 로 받은 자리를 물어
이어붙이기, 429·5xx 지수 백오프, 오프라인이면 `online` 이벤트까지 대기,
폰은 조각 2MB, 업로드 중 `wakeLock`.

엣지를 화면 없이 띄워 **실제로 눌러 봅니다** — 사진을 넣고, 모자이크를 칠하고, 펜으로 긋고,

## 좌표는 **고정 오프셋**으로 구한다

이 창 크기에서 페이지 왼쪽 위 모서리는 화면 좌표 **(13, 172)**, 화면 배율 **dpr 2** 입니다.
브라우저에 아래를 넣고 `__r('선택자')` / `__btn('버튼 글자')` 를 부르면 `x,y,w,h` 가 바로 나옵니다.

```js
const OX = 13, OY = 172, D = 2;
window.__S = (r, p = 6) => [Math.round((r.left-p)*D+OX), Math.round((r.top-p)*D+OY),
                            Math.round((r.width+p*2)*D), Math.round((r.height+p*2)*D)].join(',');
window.__r = (s, p) => { const e = document.querySelector(s); return e ? __S(e.getBoundingClientRect(), p) : 'NF:'+s; };
window.__btn = (t, p) => { let h = null;
  for (const e of document.querySelectorAll('button,a[href],summary,[role=button],[role=option],[role=menuitem],nav a')) {
    if (!(e.innerText||'').trim().includes(t)) continue;
    const r = e.getBoundingClientRect(); if (!r.width || !r.height) continue;
    const a = r.width*r.height; if (!h || a < h.a) h = {e, a}; }
  return h ? __S(h.e.getBoundingClientRect(), p) : 'NF:'+t; };
```

## PowerShell·도구 함정 (v4 에서 실제로 밟은 것)

- **콤마가 뺄셈보다 세게 묶입니다.** `@($a - $x, $b - $y)` 는 `$a - ($x,$b) - ...` 로 해석돼 터집니다.
  → 항목마다 괄호: `@(($a - $x), ($b - $y))`
- **중첩 배열은 `return` 에서 펼쳐집니다.** 사각형 목록은 `[Drawing.Rectangle]` 로 담아 `return ,$list`
- **변수 이름은 대소문자를 안 가립니다.** `$h = 창핸들` 이 `-H` (높이) 파라미터를 덮어써서
  창 높이만 안 바뀌는 일이 있었습니다. 핸들은 `$hwnd` 로 쓰세요
- `movewin` 은 **두 번 불러야** 최대화가 풀리고 크기가 먹습니다
- **`javascript_tool` 은 Promise 를 기다리지 않습니다.** `{}` 만 돌아옵니다.
  → 「누르기」와 「재기」를 **다른 호출로 나누세요**
- 반환값에 **쿼리스트링이 붙은 주소**가 들어가면 도구가 결과를 통째로 막습니다. `location.href` 를 돌려주지 마세요
- 페이지가 새로 뜨면 `window.__r` 같은 도우미가 사라집니다. **이동할 때마다 다시 심으세요**

## v4 에서 찾아 고친 진짜 결함

### 📚 엮어내기가 눌러도 안 열렸다 (`dfe5bb7`)

사용자가 「엮어내기 눌러도 반응이 없다」고 해서 찾았습니다.

```js
// openCompile() 안, 고를 목록을 그리는 자리
row.appendChild(el("span", "pmeta", (n.createdAt || "").slice(0, 10)));   // ← 여기서 터진다
```

`createdAt` 은 **숫자(epoch ms)** 입니다. 숫자에는 `.slice()` 가 없어서 예외가 나고,
그 예외가 `pool.forEach` 를 뚫고 나가 **`modalHost.appendChild(bg)` 까지 못 갑니다.**
그래서 화면에 아무것도 안 뜨고 **버튼이 죽은 것처럼 보였습니다.**

같은 함수가 이미 쓰고 있던 `localDay()` 로 바꿨습니다.

> 옛 인수인계서의 「`createdAt.slice(0,10)` 은 UTC 라 하루 어긋남」이라는 메모는
> **지금은 더 위험합니다. 하루 어긋나는 게 아니라 그 화면이 통째로 안 열립니다.**
> 날짜를 뽑을 때는 반드시 `localDay()` 나 `formatDate()` 를 쓰세요.

### 엮어낸 `.md` 에서 사진 경로가 깨졌다 (`45d2769`)

엮어내기를 고쳐서 실제로 뽑아 보니 나온 문제입니다. 한 파일 안에서 이렇게 나왔습니다.

```markdown
## 1. 연결점검
![…](2026-08-17_연결점검_01.png)        ← 이 사진은 하위 폴더 안에 있다

## 2. 직접 넣은 노트
![…](점검용_직접넣은노트_01.png)          ← 이 사진은 최상위에 있다
```

**한 파일인데 편마다 기준 폴더가 다릅니다.** 어디에 저장해도 둘 중 하나는 깨집니다.
원인은 엮어내기가 한 편짜리와 **같은 `blocksToMarkdown()`** 을 쓰는데, 그 함수는 사진을
**파일 이름만으로** 가리키기 때문입니다. 한 편짜리는 자료와 같은 폴더에 있으니 맞습니다.

`blocksToMarkdown(n, h, base)` 로 앞에 붙일 폴더를 받게 하고, 엮어내기에서만
`n.folderName + "/"` 을 넘깁니다. **엮은 책은 「연결 폴더 바로 아래」에 두고 보는 것**이 기준입니다.
HTML 로 엮는 쪽은 드라이브 링크를 쓰므로 손댈 것이 없습니다.

**고친 뒤 다시 뽑아 확인했습니다 ✅**

```markdown
1편: ![…](2026-08-17_경험_연결점검/2026-08-17_연결점검_01.png)   ← 폴더가 붙음
2편: ![…](점검용_직접넣은노트_01.png)                            ← 최상위라 그대로
```

목차·앵커·본문·첨부 링크·연결 정보까지 모두 정상이었습니다.

### 「폴더 훑어서 가져오기」를 못 찾겠다 (`dfe5bb7`)

「저장 위치」 탭 **맨 아래 4단계**에 묻혀 있었습니다. 사용자가 「고급」 부터 찾다가 못 봤습니다.
**설정이 아니라 관리 작업**이므로 「고급」 탭 맨 위로 옮기고, 「드라이브에서 기록 다시 불러오기」도
같이 옮겼습니다. 원래 자리에는 길만 한 줄 남겼습니다.

> 이 수정은 **원본과 사본(`my-googlenote`) 양쪽에 넣었습니다.** 사본은 템플릿으로 뜬 별개
> 저장소라 원본을 고쳐도 따라오지 않습니다. 사본에서 확인할 일이 있으면 **같은 수정을 두 번**
> 넣어야 합니다.

### 알아둘 설계 결정

- **첨부는 Blob 으로 들고 IndexedDB 에 보관**. localStorage 에는 절대 넣지 않음
  → 블록 복사는 반드시 `cloneBlock()`. `JSON.parse(JSON.stringify())` 쓰면 **Blob 이 뭉개짐**
- **삭제는 tombstone** 으로 전파
- **관계는 두 종류** — 글 속 `[[링크]]` 와 `relations[]`. `linkData()` 에서 합침
- **코드 삽입은 sandbox iframe**, `allow-same-origin` 절대 주지 말 것
- 캔버스(관계망)는 **매 프레임 크기 동기화** 필요
- **블록→마크다운/HTML 은 함수로 분리돼 있음**(`blocksToMarkdown(n, h)` / `blocksToHtml(n, h)`)
- **날짜만 뽑을 때는 `localDay()`** 를 쓸 것. `createdAt.slice(0,10)` 은 UTC 라 하루 어긋남
- **`slim()` 은 흰 목록(whitelist)** 이다. 기록에 새 항목을 더하면 여기에도 적어야
  다른 기기로 넘어간다 (v5 에서 `shareUrl` 을 더했다)
- **모자이크·손 메모는 «원본 + 덧그린 목록»** 으로 들고 있다가 매번 다시 그린다.
  캔버스에 곧바로 칠하지 말 것 — 되돌리기가 사라진다
- **모달을 닫을 때 치울 것이 있으면 `modalCleanup`** 에 넣는다 (`closeModal()` 이 부른다)
- **공유 창은 `z-index: 170`** 이다. 「전체 보기」가 140 이라 그 위로 올려야 보인다

## 로컬에서 띄우는 법

`http://localhost:8000` 이 OAuth 승인된 원본이라 로그인까지 테스트 가능합니다.

```bash
powershell -ExecutionPolicy Bypass -File docs/점검도구/띄우기.ps1
```

저장소를 그대로 `http://localhost:8000` 으로 띄웁니다 (사본을 만들지 않으니 고치면 바로 반영).

> ⚠️ **`.ps1` 파일은 «BOM 붙은 UTF-8» 로 저장해야 합니다.** BOM 이 없으면 파워셸 5.1 이
> ANSI 로 읽어서 경로의 한글이 깨지고 따옴표가 어긋나 파싱 오류가 납니다.
> `[System.IO.File]::WriteAllText($p, $t, (New-Object System.Text.UTF8Encoding($true)))`

**이 노트북에 있는 것: git · node(v24.19.0) · python(3.12) · 엣지.** 없는 것: gh CLI.
(예전 인수인계서에 「python·node 없음」이라 적혀 있던 것은 **지금은 틀렸습니다.**)

### 커밋할 때

- 커밋 메시지에 `->` 를 쓰면 PowerShell 이 git 인자로 잘못 넘겨 실패합니다.
  **메시지는 파일로 만들어 `git commit -F 파일`**
- `Out-File -Encoding utf8` 은 **BOM 을 붙여** 커밋 제목 앞에 깨진 글자가 들어갑니다.
  `[System.IO.File]::WriteAllText($p, $t, (New-Object System.Text.UTF8Encoding($false)))` 를 쓰세요
- `D:\구글 기록장\...` 경로에 `Remove-Item` 을 쓰면 보호 규칙에 막힙니다. `git rm` 도 같은 이유로 막힘
