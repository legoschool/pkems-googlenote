## 📝 이름 — 도구는 「구글 기록장」, 체계는 「TRACE」

**TRACE** — **T**eaching · **R**ecord · **A**rchive · **C**onnection · **E**xperience

> ⚠️ **둘을 섞지 마세요.** 사람이 쓰는 도구 이름은 **구글 기록장**입니다.
> **TRACE** 는 그 도구가 속한 **체계(관리 체계)** 이름입니다.
> 구글 로그인 동의 화면에 뜨는 이름도 **「구글 기록장」** 이고, 그대로 두는 것이 맞습니다.
>
> 이름이 두 번 바뀌었습니다: **PKEMS → PEER → TRACE.**
> 이어받기는 **사슬**로 되어 있습니다 — 새 이름이 비면 `peer.` 를 보고, 그것도 없으면 `pkems.` 를 봅니다.

### ⚠️ 이름을 더 손댈 때 반드시 알아야 할 것

이름은 **화면에만 있는 게 아니라 자료에도 박혀 있습니다.** 여기를 잘못 건드리면
**쓰던 사람의 기록이 통째로 «없는 것»이 됩니다.** 화면 결함이 아니라 자료 사고입니다.

|---|---|---|
| 드라이브 | `TRACE-index.json` · `TRACE-settings.json` | `findOrInherit()` — 옛 이름들을 **최근 것부터** 찾아 하나라도 있으면 **파일 ID 는 그대로 두고 이름만** PATCH 로 바꾼다. 새로 만들지 않으므로 안에 든 것이 안 움직인다. 이름 바꾸기가 실패해도 그 파일을 그대로 쓴다 |

## 🕳️ 이번에 밟은 함정 모음 — 다음 사람은 그냥 지나가세요

같은 자리에 두 번 빠진 것도 있습니다. 코드가 아니라 **일하는 방식**의 함정입니다.

| 함정 | 어떻게 드러났나 | 어떻게 피하나 |
|---|---|---|
| **`var()` 는 «선언한 곳» 에서 풀린다** | `--entry-bg: var(--c-soft)` 로 짰는데 카드가 제 색을 못 입었다 | 카드마다 달라지는 값은 **카드에서** 풀리게 쓴다. 우리는 «덮개(`--veil`)를 걷는» 방식으로 뒤집었다 |
| **점검 잣대가 배경 «그림» 을 못 본다** | 멀쩡한 「기본」이 대비 미달로 나왔다 | `backgroundImage` 도 함께 본다 (`대비점검.mjs`) |
| **헤드리스 브라우저가 안 죽고 남는다** | 「＋버튼 0개」 같은 헛된 실패. 멀쩡한 코드를 의심했다 | 점검을 이어 돌리기 전에 포트 9xxx 짜리 msedge 를 죽인다 |
| **가짜 드라이브가 뜰 때마다 `localStorage` 를 비운다** | 새로고침이 필요한 점검을 짤 수 없었다 | `sessionStorage 'keep'` 빗장을 건다 (`자료가져오기.mjs`) |
| **셸 heredoc 이 백슬래시를 먹는다** | 정규식 `\.` 가 `.` 이 되어 아무 글자나 걸렸다. 파일 경로도 깨졌다 | 정규식·경로가 든 스크립트는 **Write 도구로** 쓴다. 셸을 거치지 않는다 |
| **파이썬 쓰기가 중간에 실패하면 파일이 0바이트가 된다** | 점검 파일 하나가 통째로 잘렸다 (커밋에서 되살림) | 한글이 든 파일은 **Write/node** 로 쓴다. `print` 인코딩도 실패 원인이 된다 |
| **점검이 엉뚱한 카드를 집는다** | 목록 맨 위에 사진 1100장이 깔려 있어 다른 기록의 줄을 눌렀다 | 검색으로 좁힌 뒤에 누른다 |
| **이름이 겹친다** | 「블록」을 찾다가 「블록**놀이**」가 먼저 잡혔다 | 이름 칸만 정확히 견준다 |

# ▶▶ v5 이어 작업 (2026-08-21) — 십삼 년치를 실제로 끌어올 수 있게

**「이 도구를 만든 진짜 목적」이라고 적어 두었던 것을 열었습니다.**
그전까지 📥 폴더 훑어서 가져오기는 **`.md` 만** 색인에 넣었습니다.
그런데 십삼 년 동안 쌓인 것은 대부분 글이 아니라 **자료**입니다 —
한글 학습지, 발표 자료, 단원평가, 수업 사진, 연수 PDF. 그게 하나도 못 들어왔습니다.

| 무엇 | 전 | 후 |
|---|---|---|
| 색인에 들어가는 것 | `.md` 만 | **글(`.md`) + 자료 전부** — 한글·발표·표·PDF·사진·영상·소리·묶음·구글 문서 |
| 파고드는 깊이 | 5단계 | **10단계** (`SCAN_DEPTH`) |
| 훑는 폴더 수 | 400곳 | **3000곳** (`SCAN_FOLDER_MAX`) |
| 한 폴더에 1000개 넘을 때 | **1001번째부터 조용히 없는 것이 됨** | 쪽을 넘겨 **다 받는다** (`nextPageToken`) |
| 한 번에 넣는 자료 수 | — | **3000개** (`IMPORT_MAX`). 넘치면 최근에 고친 것부터 |

### 어떻게 세우는가

자료 파일 하나가 **기록 한 편**이 됩니다. **원본은 옮기지도 고치지도 않습니다.**
색인이 그 파일을 **가리키기만** 합니다.

- 사진 → `image` 블록 (목록에서 바로 보인다) · 그 밖 → `file` 블록 (첨부 줄)
- **구글 문서·시트·슬라이드 → `link` 블록.** 내려받을 실체가 없어서 링크로 겁니다
- **거쳐 온 폴더 이름이 태그가 됩니다** — `2019/3학년/과학/` 이면 `#2019 #3학년 #과학`
  (위로 3겹까지, `IMPORT_TAG_DEPTH`). 그래서 「태그가 곧 폴더」와 관계망에 그대로 들어옵니다
- 유형은 **「자료」**. 없으면 맨 앞 유형

### 말없이 수천 개를 넣지 않습니다

십삼 년치는 수천 개가 나옵니다. 그래서 넣기 전에 **무엇이 몇 개인지 보여 주고 물어봅니다** —
「사진 1,204개 · 한글 312개 · PDF 88개…」. 글(`.md`)은 물어보기 **전에** 먼저 읽습니다.
그래야 「그 글에 딸린 사진」이 자료 수에서 빠져서, 보여 주는 숫자가 정직해집니다.

> `confirmModal` 에 **`okLabel`·`onCancel`** 을 붙였습니다.
> ⚠️ `onCancel` 은 취소·바깥 누름 **어느 쪽이든 꼭 한 번** 불려야 합니다.
> 안 불러 주면 기다리던 약속(Promise)이 **영영 안 풀려** 가져오기가 멈춘 채로 끝납니다.

> 📌 **`""`(빈 값)과 `"base"` 는 다르다.** 빈 값은 «아직 안 골랐다», `base` 는 «기본을 골랐다».
> 같게 두면 기본을 고른 사람에게 매번 다시 묻는다.

#### 🎨 색을 손대면 반드시 `대비점검.mjs` 를 돌리세요

프리셋 일곱 × 밝은/어두운 × 데스크톱/폰 = **스물여덟 자리**를 수치로 잽니다.
눈으로는 못 잡습니다 — **「블록놀이」의 «아이디어» 배지가 3.15:1** 이었습니다.
하필 아이가 볼 화면인데, 화면으로는 그냥 «노란 배지» 로 보여서 못 알아챘습니다.

```bash
node docs/점검도구/대비점검.mjs <그림 넣을 폴더> http://localhost:8000/
```

마지막 점검에서 열두 곳을 기준(4.5:1)에 맞췄습니다 — 색조는 그대로 두고 밝기만 옮겼습니다.

| 고친 곳 | 전 → 후 |
|---|---|
| 블록놀이 유형1·3·4·5 | 4.12 · **3.15** · 3.45 · 4.13 → 4.77 · 4.63 · 4.75 · 4.75 |
| 설계도 유형1·3·4 | 4.29 · 4.23 · 4.24 → 4.71 · 4.71 · 4.80 |
| 메모지·블록·공책 `--ink-soft` | 4.39 → 4.75 (밝은 화면) |
| 블록놀이 `--ink-soft` | 4.48 → 4.68 |
| 종이 계열 어두운 화면 `--ink-soft` | 4.32 → 4.75 |

> 🕳️ **잣대를 짤 때도 한 번 빠졌습니다.** 배경 «색» 만 보면 안 됩니다.
> 기록 카드는 유형 색을 색으로 깔고 그 위에 덮개(`--veil`)를 배경 «그림» 으로 칠합니다.
> 색만 보면 가려진 틴트를 배경으로 잡아, **멀쩡한 것을 «미달» 이라고** 말합니다.
> 처음 재었을 때 「기본」이 미달로 나온 게 그 탓이었습니다.

#### ⚠️ 다음 사람이 반드시 지켜야 할 한 가지

**프리셋마다 화면 CSS 를 따로 쓰지 마세요.** 그러면 기능을 하나 고칠 때마다 네 벌을 고쳐야 하고,
한 벌을 빼먹는 순간 그 프리셋만 깨집니다. 규칙은 이렇습니다.

- 화면 CSS 는 **하나뿐**이다. 프리셋은 `:root` 의 **토큰 값만** 갈아 끼운다
- 새 화면을 만들 때 색·테두리 굵기·모서리를 **숫자로 쓰지 말고 토큰으로** 쓴다
  (`var(--bw)` · `var(--r-btn)` · `var(--radius)` · `var(--font-title)` …)
- 그러면 **새 기능이 네 프리셋에 저절로 따라온다.** 프리셋을 손댈 일이 없다

| 토큰 | 무엇 |
|---|---|
| `--font-body` · `--font-title` · `--title-spacing` | 글꼴. 손글씨(Gaegu)는 **제목·단추에만** |
| `--bw` | 테두리 굵기 (1px ↔ 2.5px) |
| `--radius` · `--r-btn` · `--r-btn-sm` · `--r-inp` · `--r-pill` · `--r-block` | 모서리. 메모지는 여기에 **삐뚤한 값**을 넣어 손그림처럼 만든다 |
| `--veil` | 기록 카드의 **종이색 덮개**. `transparent` 로 바꾸면 유형 색이 드러난다 |
| `--entry-pt` · `--accent-w` · `--accent-l` | 카드 위 여백 · 위 색줄 · 왼 색줄 |
| `--stud` · `--stud-w` · `--stud-h` · `--stud-step` | 레고 돌기 — 켜기 · 줄 너비 · 지름 · 간격 |
| `--warn-bg/line/ink` · `--ok-…` · `--pin-bg` | 알림 띠와 고정 딱지. 뜻은 그대로 두고 **색만** 프리셋이 고른다 |
| `--t1`~`--t6` · `--t1s`~`--t6s` | **유형 색 여섯 자리** (진한 색 / 연한 색) |

#### ⚠️ 유형 색은 «키» 가 아니라 «차례» 로 준다

사용자가 유형을 더 만들 수 있습니다. 색을 `experience` 같은 **키로 정하면 사용자가 만든 유형에는
색이 없어집니다.** 그래서 `typeVars()` 가 유형의 **자리(index)** 를 여섯으로 나눠 돌려 씁니다.

#### 🕳️ 여기서 한 번 빠졌습니다 — `var()` 는 «선언한 곳» 에서 풀린다

`--entry-bg: var(--c-soft, var(--panel))` 이라고 써 놓고 카드마다 `--c-soft` 를 달았는데,
**카드는 제 색을 못 입었습니다.** 안쪽 `var()` 는 그 토큰을 **선언한 곳(html)** 에서 풀리기 때문입니다.
거기엔 `--c-soft` 가 없으니 언제나 대비값(`--panel`)이 됐습니다.

고친 방법 — **덮개를 걷는 방식**으로 뒤집었습니다.
카드 바탕색은 언제나 유형 색이고(`background-color: var(--c-soft, …)` — 이건 **카드에서** 풀린다),
그 위에 `--veil` 색을 한 겹 덮습니다. 기본·공책은 종이색으로 덮어 가리고, 메모지·블록은 `transparent` 로 걷습니다.

### 🌐 «웹 쪽으로» 공유 — 사진·영상·녹음까지 (view.html)

사용자가 «HTML 로, 사진·영상·녹음이 잘 보이게» 를 원했다. 앞의 두 길로는 안 된다.

| 길 | 왜 모자란가 |
|---|---|
| `.html` 파일을 드라이브에 올리기 | **드라이브가 웹페이지로 안 연다** (2016년에 정적 호스팅을 없앴다). 내려받기 화면만 뜬다 |
| 구글 문서 «웹에 게시»(`/pub`) | 사진은 실리지만 **영상·녹음은 못 싣는다** |

그래서 **읽는 쪽 `view.html` 을 이 저장소에 두었다.** 저장소 전체가 Pages 로 배포되니 새 서버가 필요 없다.

- **글·제목·태그·고른 모양**은 **주소 뒤(`#d=`)** 에 gzip 으로 눌러 담아 보낸다 → 서버도, 새 열쇠(API 키)도 필요 없다
- **사진·영상·녹음**은 드라이브에서 바로 불러온다 (`<img>` · `<iframe>` 은 CORS 를 안 탄다)
- 실제로 재 보니 꽤 긴 기록도 **700~800자** 였다. 카톡에 넣을 만하다

```
보내는 쪽 index.html : buildSharePacket → encodePacket → view.html#d=...
받는 쪽  view.html   : decodePacket → render
```

> 📌 **`encodePacket`(index.html)과 `decodePacket`(view.html)은 «짝»이다.**
> 맨 앞 한 글자가 표시 — `1` 은 눌러 담은 것, `0` 은 그냥 담은 것.
> 한쪽만 고치면 링크가 통째로 안 펴진다. 꾸러미 모양(`{v,t,d,g,th,b}`)도 마찬가지다.

#### 드라이브에서 남에게 보여 주는 주소 (문서에 없는 길이다)

| 무엇 | 주소 |
|---|---|
| 사진 | `lh3.googleusercontent.com/d/{id}=w1600` → 막히면 `drive.google.com/thumbnail?id=…` → 그것도 막히면 **«열어 보기» 링크로 내려간다** |
| 영상·녹음 | `drive.google.com/file/d/{id}/preview` 를 `<iframe>` 으로 |

> ⚠️ **구글이 문서로 약속한 주소가 아니다.** 언젠가 바뀔 수 있어서 사진에는 두 겹의 대비책을 뒀다.
> 대비책이 없으면 받는 사람 화면에 **깨진 그림만** 남는다.

> ⚠️ **녹음 칸을 62px 로 두면 안 된다.** 우리 재생기가 아니라 «드라이브가 그리는 쪽» 이라
> 잘려서 「Google Drive」 글자만 보인다. 168px 준다.

> ⚠️ **주소의 `#` 만 바뀌면 브라우저는 쪽을 다시 읽지 않는다.** `hashchange` 를 듣지 않으면
> 링크 두 개를 이어서 열었을 때 앞의 기록이 그대로 남는다.

> ⚠️ **`CompressionStream` 의 `write()`·`close()` 가 돌려주는 약속을 그냥 두면 안 된다.**
> 링크가 잘려 풀다 막히면 «아무도 안 받은 거부» 가 되어 콘솔에 오류로 남는다. 양쪽 다 `.catch` 로 삼킨다.

> ⚠️ **이 길은 딸린 파일을 하나씩 «링크가 있는 사람 = 읽기» 로 엽니다.** 그래서 공유 창의
> **사진 확인 관문**을 반드시 지나야 한다. «공유 끄기» 는 그 파일들의 권한을 도로 거둔다.

**점검**: `node docs/점검도구/공유쪽.mjs` — 16가지. 진짜 `view.html` 이 펴는 것까지 본다.
다만 **사진·영상이 실제로 보이는지는 실제 계정이라야 안다** (여기서는 가짜 ID라 대비책으로 내려간다).

### 🌐 웹 페이지로 공유 — 드라이브는 HTML 을 못 연다

**`.html` 을 드라이브에 올려 링크를 줘도 «웹페이지» 로 안 열린다.**
구글이 2016년에 드라이브의 정적 웹 호스팅을 없앴다 — 내려받기 화면만 뜬다.

대신 **구글 문서를 «웹에 게시»** 한다 (`publishDocToWeb`). 문서의 판(revision)에 `published` 를 켜는 것이라
편집 화면이 아니라 **읽는 쪽(`/pub`)** 이 열린다. 사진·링크·소제목이 그대로 있고, 받는 사람은 로그인이 필요 없다.
`publishAuto` 를 켜야 나중에 고친 것이 게시된 쪽에도 따라간다.

### 🔲 모자이크 칸 굵기를 고를 수 있게

칸 크기가 `r / 4` 로 고정이라 원 하나에 여덟 칸뿐이었다 — 굵을 수밖에 없었다.
`GRAINS` 로 **곱게 · 보통 · 굵게** 를 두고 기본을 «보통»(`r / 7`)으로 내렸다. `settings.maskGrain` 에 남는다.

> 곱게 갈수록 보기엔 곱지만 **원래 얼굴이 되살아 보인다.** 그래서 사람이 고르게 두었다.

### 🗃️ 목록 보기 = 디렉토리 · 연결을 그 자리에서

목록 보기가 **지금 정리 방식대로 폴더에 담겨** 나온다 (`listFolderOf()`). 드라이브를 열었을 때와 같은 모양이라
화면과 드라이브가 어긋나지 않는다. 폴더 줄을 눌러 접었다 편다.

🔗 를 누르면 **이어진 기록이 그 자리에서 펼쳐진다** (`linkOpen`). 잇거나 끊는 것은 여전히 편집·관계망에서 한다.

> ⚠️ `outLinks` 는 `{ to, label }`, `backLinks` 는 **`{ entry, label }`** 이다. 생김새가 다르다.
> 한 가지로 뭉뚱그리면 «들어오는 연결» 이 통째로 안 보인다. 한 번 그렇게 짰다가 고쳤다.
> ⚠️ 폴더 이름이 날짜로 시작하므로 **내림차순** 이라야 최신이 위로 온다.

### 🔄 「폴더 구조」 창은 드라이브를 읽는 것이 아니었다

사용자가 드라이브에서 **손으로 만든 폴더가 안 나온다**고 했다. 맞다 — 이 창은 색인으로 그린
**«이렇게 됩니다» 예상도**였다. 아무리 다시 열어도 안 나온다.

- 그 사실을 **화면에 적어 두었다.** 말해 주지 않으면 «고장 났다» 고 여긴다
- **「🔄 드라이브에서 다시 읽기」** 를 넣었다 (`buildLiveTree`). 진짜로 훑어 지금 있는 그대로 그린다
- ⚠️ `scanFolder` 가 **지나간 폴더도 적어 두게**(`dirs`) 고쳤다. 파일만 모으면 **빈 폴더가 통째로 사라진다** —
  손으로 만들어 아직 아무것도 안 넣은 폴더가 딱 그 경우다

이 앱에서 **`folderId` 는 「이 기록이 가진 폴더」** 라는 뜻입니다. 코드 네 군데가
그 뜻을 믿고 움직입니다. 그런데 가져온 기록에 **원본이 있던 남의 폴더**를 `folderId` 로
넣어 두었더니, 그 네 군데가 전부 **십삼 년치가 든 폴더**를 향했습니다.

| 어디 | 무슨 일이 벌어졌나 |
|---|---|
| `removeEntry` | 학습지 **한 편** 지우면 `trashFile(n.folderId)` → **`2019/3학년/과학/` 이 통째로 휴지통행** |
| `openShareModal` 의 «📁 폴더 통째로» | 자료 하나 공유하려다 **그 폴더 전체가 «링크 있는 사람 = 읽기»** 가 됨 |
| `relocateEntryFiles` | 한 번 고쳐 저장하면 원본이 **십삼 년 있던 자리에서 새 폴더로 끌려 나옴** |
| `saveEntry` | 첨부 줄을 빼고 저장하면 `trashFile(b.fileId)` → **원본 파일이 휴지통행** |

**고친 방법 — 이름을 갈라 놓았습니다.**

- 가져온 기록은 **`folderId` 를 갖지 않습니다.** 대신 **`srcFolderId`·`srcFolderName`**
  («원본이 있던 곳») 에 적고, **길 안내에만** 씁니다 — 화면에 「📁 **원본** 폴더」로 뜹니다
- `removeEntry` 는 `srcId` 가 있으면 **아무것도 안 버리고 목록에서만 뺍니다.**
  확인 창 문구도 「목록에서만 뺍니다 … 원본 파일은 그대로 남습니다」로 갈라 씁니다
- `relocateEntryFiles`·`saveEntry` 는 **`fileId === n.srcId` 인 것을 건너뜁니다**

> 📌 **다음에 `folderId` 를 쓸 일이 생기면 먼저 물어보세요 — 「이 폴더는 이 기록이 만든 것인가?」**
> 아니라면 `folderId` 에 넣으면 안 됩니다. 이름이 같다고 뜻이 같지 않습니다.

> 📌 **`srcFolderId`·`srcFolderName` 도 `slim()` 에 넣어야 합니다.** 안 그러면
> 새로고침 한 번에 「📁 원본 폴더」가 사라집니다.

### ⚠️ 아직 그대로 둔 것 — 가져온 `.md` 를 고치면 원본이 옮겨집니다

가져온 **`.md`** 는 `srcId` 가 없습니다. 그건 «파일을 가리키는 것» 이 아니라 **기록 그 자체**라서,

바꾸려면 가져온 `.md` 에도 «제자리에 둔다» 표시를 달아야 하는데,
그러면 v5 의 동작이 바뀌므로 **사용자에게 물어보고 정하세요.**

## ⚠️ v5 에서 알아낸 것 — 다음 사람이 꼭 알아야 할 두 가지

### 1. 구글 토큰 창은 «조용히» 열 수 없다

`google.accounts.oauth2` 에는 **«조용히 받기» 라는 길이 없습니다.** 부르면 **무조건 팝업**입니다.
사용자가 아무것도 안 누른 상태(예: 페이지 로드 직후)에서 부르면 브라우저가
「내가 안 시킨 창」으로 보고 **막습니다.** 그리고 예전 코드는 그 실패를
`.catch(function(){})` 로 삼켰습니다 — **이것이 「폰에서 로그인이 풀린다」의 진짜 정체입니다.**

지금은 이렇게 합니다.
- 토큰을 **만료시각과 함께 `localStorage`** 에 둔다 (`trace.token.v1`). 살아 있으면 그대로 쓴다
- `canOpenPopup()` — **최근 60초 안에 누른 적이 있을 때만** 토큰 창을 연다
- 못 열면 조용히 넘어가지 않고 `needReconnect = true` → **「다시 연결」 띠**

> 이 사실을 모르고 「startup 에서 조용히 갱신하자」고 고치면 **원래 버그로 되돌아갑니다.**

### 2. `fetch` 로는 업로드 진행률을 못 낸다

`fetch()` 에는 **업로드 진행 이벤트가 아예 없습니다.** 그래서 예전에는 조각(8MB) 하나가
끝나야 진행률이 움직였고, 폰에서 그건 **20~60초 동안 `0%` 에 붙어 있는 것**이었습니다.
사용자가 말한 「멈춘 채로 있어」가 이것이었습니다.

지금은 `XMLHttpRequest` + `xhr.upload.onprogress` 입니다. 되돌리지 마세요.
함께 들어간 것: **45초 정지 감지**(`STALL_MS`) → 끊고 `bytes */total` 로 받은 자리를 물어
이어붙이기, 429·5xx 지수 백오프, 오프라인이면 `online` 이벤트까지 대기,
폰은 조각 2MB, 업로드 중 `wakeLock`.

## 좌표는 **고정 오프셋**으로 구한다

이 창 크기에서 페이지 왼쪽 위 모서리는 화면 좌표 **(13, 172)**, 화면 배율 **dpr 2** 입니다.
브라우저에 아래를 넣고 `__r('선택자')` / `__btn('버튼 글자')` 를 부르면 `x,y,w,h` 가 바로 나옵니다.

```js
const OX = 13, OY = 172, D = 2;
window.__S = (r, p = 6) => [Math.round((r.left-p)*D+OX), Math.round((r.top-p)*D+OY),
                            Math.round((r.width+p*2)*D), Math.round((r.height+p*2)*D)].join(',');
window.__r = (s, p) => { const e = document.querySelector(s); return e ? __S(e.getBoundingClientRect(), p) : 'NF:'+s; };
window.__btn = (t, p) => { let h = null;
  for (const e of document.querySelectorAll('button,a[href],summary,[role=button],[role=option],[role=menuitem],nav a')) {
    if (!(e.innerText||'').trim().includes(t)) continue;
    const r = e.getBoundingClientRect(); if (!r.width || !r.height) continue;
    const a = r.width*r.height; if (!h || a < h.a) h = {e, a}; }
  return h ? __S(h.e.getBoundingClientRect(), p) : 'NF:'+t; };
```

> **`outerHeight`·`screenY` 로 오프셋을 계산하지 마세요.** 그 값은 「디버깅 안내 띠」가 떠 있는 동안 측정되고,
> 정작 사진을 찍을 때는 띠가 사라져 있어서 **126px 이 어긋납니다.** v4 에서 이것 때문에 세 번 다시 찍었습니다.

## PowerShell·도구 함정 (v4 에서 실제로 밟은 것)

- **콤마가 뺄셈보다 세게 묶입니다.** `@($a - $x, $b - $y)` 는 `$a - ($x,$b) - ...` 로 해석돼 터집니다.
  → 항목마다 괄호: `@(($a - $x), ($b - $y))`
- **중첩 배열은 `return` 에서 펼쳐집니다.** 사각형 목록은 `[Drawing.Rectangle]` 로 담아 `return ,$list`
- **변수 이름은 대소문자를 안 가립니다.** `$h = 창핸들` 이 `-H` (높이) 파라미터를 덮어써서
  창 높이만 안 바뀌는 일이 있었습니다. 핸들은 `$hwnd` 로 쓰세요
- `movewin` 은 **두 번 불러야** 최대화가 풀리고 크기가 먹습니다
- **`javascript_tool` 은 Promise 를 기다리지 않습니다.** `{}` 만 돌아옵니다.
  → 「누르기」와 「재기」를 **다른 호출로 나누세요**
- 반환값에 **쿼리스트링이 붙은 주소**가 들어가면 도구가 결과를 통째로 막습니다. `location.href` 를 돌려주지 마세요
- 페이지가 새로 뜨면 `window.__r` 같은 도우미가 사라집니다. **이동할 때마다 다시 심으세요**

## v4 에서 찾아 고친 진짜 결함

### 📚 엮어내기가 눌러도 안 열렸다 (`dfe5bb7`)

사용자가 「엮어내기 눌러도 반응이 없다」고 해서 찾았습니다.

```js
// openCompile() 안, 고를 목록을 그리는 자리
row.appendChild(el("span", "pmeta", (n.createdAt || "").slice(0, 10)));   // ← 여기서 터진다
```

`createdAt` 은 **숫자(epoch ms)** 입니다. 숫자에는 `.slice()` 가 없어서 예외가 나고,
그 예외가 `pool.forEach` 를 뚫고 나가 **`modalHost.appendChild(bg)` 까지 못 갑니다.**
그래서 화면에 아무것도 안 뜨고 **버튼이 죽은 것처럼 보였습니다.**

같은 함수가 이미 쓰고 있던 `localDay()` 로 바꿨습니다.

> 옛 인수인계서의 「`createdAt.slice(0,10)` 은 UTC 라 하루 어긋남」이라는 메모는
> **지금은 더 위험합니다. 하루 어긋나는 게 아니라 그 화면이 통째로 안 열립니다.**
> 날짜를 뽑을 때는 반드시 `localDay()` 나 `formatDate()` 를 쓰세요.

### 엮어낸 `.md` 에서 사진 경로가 깨졌다 (`45d2769`)

엮어내기를 고쳐서 실제로 뽑아 보니 나온 문제입니다. 한 파일 안에서 이렇게 나왔습니다.

```markdown
## 1. 연결점검
![…](2026-08-17_연결점검_01.png)        ← 이 사진은 하위 폴더 안에 있다

## 2. 직접 넣은 노트
![…](점검용_직접넣은노트_01.png)          ← 이 사진은 최상위에 있다
```

**한 파일인데 편마다 기준 폴더가 다릅니다.** 어디에 저장해도 둘 중 하나는 깨집니다.
원인은 엮어내기가 한 편짜리와 **같은 `blocksToMarkdown()`** 을 쓰는데, 그 함수는 사진을
**파일 이름만으로** 가리키기 때문입니다. 한 편짜리는 자료와 같은 폴더에 있으니 맞습니다.

`blocksToMarkdown(n, h, base)` 로 앞에 붙일 폴더를 받게 하고, 엮어내기에서만
`n.folderName + "/"` 을 넘깁니다. **엮은 책은 「연결 폴더 바로 아래」에 두고 보는 것**이 기준입니다.
HTML 로 엮는 쪽은 드라이브 링크를 쓰므로 손댈 것이 없습니다.

**고친 뒤 다시 뽑아 확인했습니다 ✅**

```markdown
1편: ![…](2026-08-17_경험_연결점검/2026-08-17_연결점검_01.png)   ← 폴더가 붙음
2편: ![…](점검용_직접넣은노트_01.png)                            ← 최상위라 그대로
```

목차·앵커·본문·첨부 링크·연결 정보까지 모두 정상이었습니다.

### 「폴더 훑어서 가져오기」를 못 찾겠다 (`dfe5bb7`)

## 앱 구조 요약 (코드 읽기 전에)

`index.html` 단일 파일. 주석으로 섹션이 번호로 나뉩니다.

```
0    소유자 설정 (OWNER_CLIENT_ID, SCOPE, DEFAULTS, FOLDER_MODES, VIEW_MODES)
1    유틸           2  상태/localStorage/IndexedDB/임시저장
3    구글 인증 (토큰 보관·canOpenPopup·renewQuietly·reconnect)
4    드라이브 폴더 (uploadBlob/putChunk/putChunks·태그폴더·바로가기·공유권한)
5    파일 이름 규칙
5-2  위키링크/백링크/relations
6    마크다운·HTML 생성 (blocksToMarkdown / blocksToHtml / htmlPage)

8-9  임시저장(draft)
9    저장/편집     10  목록 렌더(보기 3종·슬라이드·영상)
```

v5 에서 늘어난 파일: `manifest.json` 에 `share_target`, `sw.js` 에 공유 POST 받기.

### 알아둘 설계 결정

- **첨부는 Blob 으로 들고 IndexedDB 에 보관**. localStorage 에는 절대 넣지 않음
  → 블록 복사는 반드시 `cloneBlock()`. `JSON.parse(JSON.stringify())` 쓰면 **Blob 이 뭉개짐**
- **삭제는 tombstone** 으로 전파
- **관계는 두 종류** — 글 속 `[[링크]]` 와 `relations[]`. `linkData()` 에서 합침
- **코드 삽입은 sandbox iframe**, `allow-same-origin` 절대 주지 말 것
- 캔버스(관계망)는 **매 프레임 크기 동기화** 필요
- **블록→마크다운/HTML 은 함수로 분리돼 있음**(`blocksToMarkdown(n, h)` / `blocksToHtml(n, h)`)
- **날짜만 뽑을 때는 `localDay()`** 를 쓸 것. `createdAt.slice(0,10)` 은 UTC 라 하루 어긋남
- **`slim()` 은 흰 목록(whitelist)** 이다. 기록에 새 항목을 더하면 여기에도 적어야
  다른 기기로 넘어간다 (v5 에서 `shareUrl` 을 더했다)
- **모자이크·손 메모는 «원본 + 덧그린 목록»** 으로 들고 있다가 매번 다시 그린다.
  캔버스에 곧바로 칠하지 말 것 — 되돌리기가 사라진다
- **모달을 닫을 때 치울 것이 있으면 `modalCleanup`** 에 넣는다 (`closeModal()` 이 부른다)
- **공유 창은 `z-index: 170`** 이다. 「전체 보기」가 140 이라 그 위로 올려야 보인다

## 로컬에서 띄우는 법

`http://localhost:8000` 이 OAuth 승인된 원본이라 로그인까지 테스트 가능합니다.

```bash
powershell -ExecutionPolicy Bypass -File docs/점검도구/띄우기.ps1
```

저장소를 그대로 `http://localhost:8000` 으로 띄웁니다 (사본을 만들지 않으니 고치면 바로 반영).

> ⚠️ **`.ps1` 파일은 «BOM 붙은 UTF-8» 로 저장해야 합니다.** BOM 이 없으면 파워셸 5.1 이
> ANSI 로 읽어서 경로의 한글이 깨지고 따옴표가 어긋나 파싱 오류가 납니다.
> `[System.IO.File]::WriteAllText($p, $t, (New-Object System.Text.UTF8Encoding($true)))`

**이 노트북에 있는 것: git · node(v24.19.0) · python(3.12) · 엣지.** 없는 것: gh CLI.
(예전 인수인계서에 「python·node 없음」이라 적혀 있던 것은 **지금은 틀렸습니다.**)

### 커밋할 때

- 커밋 메시지에 `->` 를 쓰면 PowerShell 이 git 인자로 잘못 넘겨 실패합니다.
  **메시지는 파일로 만들어 `git commit -F 파일`**
- `Out-File -Encoding utf8` 은 **BOM 을 붙여** 커밋 제목 앞에 깨진 글자가 들어갑니다.
  `[System.IO.File]::WriteAllText($p, $t, (New-Object System.Text.UTF8Encoding($false)))` 를 쓰세요
- `D:\구글 기록장\...` 경로에 `Remove-Item` 을 쓰면 보호 규칙에 막힙니다. `git rm` 도 같은 이유로 막힘
